# 募資頁面文案完整框架

> 從 15 份實戰範例（AIBOX、Dream Glass、ECOHEAL、Greenis、MONACOOK、Neabot、OutIn、POIEMA、SANSUI、WONDER、悠合魚缸、DIKE、JMGO、Hug 抱抱貓跳台、VELO 行李箱）歸納而成。


---

## ０｜頁面開始之前——策略定位區塊

每份範例的最上方都有一段**不會出現在頁面上**的策略備忘。這段是整份文案的指北針，所有段落的文字方向、語氣、刪減判斷都從這裡出發。

### 必填欄位

| 欄位 | 說明 | 範例（ECOHEAL） |
|------|------|-----------------|
| **產品定位** | 撇除市場，產品本身帶來什麼好處 | 醫療機構使用！PHIT 光子除味技術，把污染變成水、二氧化碳 |
| **市場定位** | 和競品比，你站在什麼位置 | 實驗室認證可消除臭味，工業技術縮小至家庭尺寸，不用換濾網 |
| **傳播定位-核心** | 最深層、品牌層級的一句話 | 不是抑制，而是主動殲滅臭味因子！ |
| **傳播定位-中層** | 功能面的核心溝通 | 最難處理的臭味，我們也能搞定 |
| **傳播定位-表層** | 消費者第一眼看到最有感的那句 | 除味不能憑感覺，得要趕盡殺絕 |

部分範例會額外加上：
- **映射在消費者心中的感受**（AIBOX：工作有效率、娛樂更輕鬆）
- **夢幻使用場景**（JMGO：躺在床上看超高清電影）
- **潛在質疑**（VELO：真的能抵三個？夠耐用嗎？）

### 段落結構矩陣（出現在幾乎所有範例）

每份範例都有一張表格，橫軸是頁面段落順序，縱軸是素材類型：

| Opening | Why | How（情境/場景） | How（功能/特色） | What（技術/材料） | What（規格） | Trust | Reward |
|---------|-----|------------------|------------------|-------------------|-------------|-------|--------|

這張表的作用是：**確保每個賣點都被分配到正確的段落位置**，不遺漏也不重複。

## １｜Opening — 破題

**目的：3 秒內抓住注意力，讓人想繼續往下看。**

### 1-1｜主視覺 + 產品名稱 + 核心一句話

所有範例的第一個段落都是：

```
【主視覺圖】
產品名稱
核心 Slogan（通常就是傳播定位的「表層」）
```

範例：
- AIBOX：「走到哪就看到哪，像自己的寶貝一直黏著」
- OutIn：「每次冒險，都值得一杯 Espresso」
- VELO：「世界唯一可伸縮的硬殼行李箱」
- Hug 貓跳台：「喵臨天下！在家打造貓的天堂」
- JMGO：「你家也有座奧斯卡」

### 1-2｜社會證明先行（選用，約 60% 的範例使用）

在正式進入痛點之前，先用一個數據或權威建立「這東西不是空穴來風」的信心：

- Neabot：「日本 Makuake 最受歡迎的掃地機，募資破億日圓」
- MONACOOK：「韓國售出超過 2 萬組，熱銷 8500 萬台幣」
- JMGO：「海外募資總額超過 2 億台幣」
- OutIn：「熱銷 40 多國！歐美亞馬遜熱銷排行第一」
- Dream Glass：「全球募資超過 5000 萬台幣」
- Hug：「全台募資金額最高的貓跳台，超過 2700 位貓奴指定」

### 1-3｜KOL / 達人推薦（選用）

部分範例在破題階段就放 KOL 推薦，製造「別人都說好」的從眾感：
- ECOHEAL：鐵爸、武敬凱、科技狗、宇宙貓咪等短句推薦
- JMGO：蘋果迷、凱特、露營大叔
- OutIn：「各路專家 - 細品推薦」

**位置邏輯：** 如果 KOL 的一句話比產品規格更能讓人「秒懂為什麼要買」，就放前面；如果 KOL 的推薦更偏向使用心得，就放 Trust 段。

## ２｜Why — 為什麼你需要這個？（製造問題意識）

**目的：讓消費者發現「原來我有這個問題」或「原來現在的做法不夠好」。**

這是整份文案最關鍵的段落——如果 Why 沒寫好，後面所有功能都沒有意義。

### 2-1｜痛點列舉法（最常見，約 80% 範例使用）

用 3-4 個具體生活場景，描述「沒有這個產品時的困擾」：

**Greenis 料理機：**
- 困擾一：烹飪器具把廚房堆得滿滿
- 困擾二：依照食譜卻無法掌握火候
- 困擾三：一次只能煮 1-2 道菜，耗時
- 困擾四：煮什麼都需站著顧火

**AIBOX 螢幕：**
- 追劇只能盯手機？小螢幕傷眼，好委屈
- 投影機找不到地方？手忙腳亂，好委屈
- 想看電影卻被家人搶先？休息還要搶，好委屈

**SANSUI 冷氣：**
- 移動冷氣四大魔王：超耗電、不會冷、搬不動、沒效率

**寫法公式：**
```
場景描述（消費者認得出來的日常）
↓
具體的不舒服感受（委屈、累、煩、無奈）
↓
隱含結論：現狀不 OK，需要被改變
```

### 2-2｜反問質疑法

用一個直球問題，讓消費者自己承認「對，我有這個問題」：

- 悠合魚缸：「討厭魚一直死心情很差？」
- ECOHEAL：「你為了對抗臭味做了多少努力？」
- VELO：「你家到底有多少行李箱？」
- POIEMA：「水污染日益嚴重，喝一杯水要等多久？」

### 2-3｜現有方案不足法

列出消費者目前的解決方式，再逐一點出缺陷：

**ECOHEAL：**
- 到處噴除臭劑（擔心化學成分）
- 空氣清淨機（沒辦法完全去味）
- 放咖啡渣、橘子皮（消耗又不美觀）
- 還是只能委屈自己隨時間散去.....

**OutIn：**
- 手沖咖啡：需要一堆裝備，準備麻煩又佔空間
- 濾掛咖啡：也要花時間煮熱水
- 即溶咖啡：味道單調無聊

### 2-4｜委屈感 / 將就感營造

不直接說「你有問題」，而是讓消費者感受到「我一直在將就」：

- AIBOX：「你今天也因為螢幕，委屈自己了嗎？」→「生活不該被螢幕綁架！可以更自由！」
- JMGO：「用他牌投影機，別再騙自己能在家看電影了」

## ３｜特色速覽 — 一張表掃完所有亮點

**目的：在深入功能之前，先給消費者一個「全貌」，讓他知道這個東西有幾個厲害的地方。**

幾乎所有範例在 Why 之後、功能展開之前，都會放一個 **6-8 格的特色速覽表**：

**OutIn Nano：**
| 黃金Crema 20 Bar | 冷熱水皆可萃取 | 92°自動加熱 | 7500mAh大電量 |
| 膠囊/咖啡粉雙模式 | IPX4防水 | 670g超輕巧 | Type-C充電 |

**SANSUI 冷氣：**
| 11°C 強力製冷 | 高效環保壓縮機 | 循環暴風量 | 輕量手提設計 |
| 390W 低瓦數 | 溫度顯示 | 多段式照明 | 雙模式雙風量 |

**Neabot Q11：**
| 集塵自動清潔 | 業界最強吸力 | 能掃能拖 | 自動迴避障礙 |
| 低噪音 | 智慧地圖偵測 | 大電池容量 | 自定打掃日誌 |

**格式規律：**
- 固定 4x2 或 3x2 的格子
- 每格 = 一個 icon + 一行關鍵字
- 語言極度精簡，只要讓人「掃到」就好
- 這張表之後才開始逐一展開功能

## ４｜How — 場景 + 功能展開

**目的：讓消費者看到「這個東西怎麼融入我的生活」和「它具體怎麼厲害」。**

這是頁面最長的區段，通常佔全頁 40-60%。

### 4-1｜場景先行，功能跟上

先畫面，後規格。先讓人「看見自己在用」，再告訴他「為什麼用起來這麼好」。

**AIBOX 的結構：**
```
大標：想怎麼看就怎麼看
  場景1：串流影音｜無線娛樂 【圖】
  場景2：高效工作｜輕鬆辦公 【圖】
  場景3：主機遊戲｜隨地暢玩 【圖】
  場景4：有氧運動｜居家健身 【圖】
  場景5：活動看板｜場地佈置 【圖】
```

**OutIn 的結構：**
```
大標：沙漠、雪地、山巔、森林、海岸
副標：沒有邊界、沒有限制
副標：極端環境也能給你穩定的好咖啡
【多張戶外場景圖】
```

### 4-2｜功能逐條展開（編號法）

當功能數量多（5 個以上），用編號逐一展開，每個功能一個段落：

**Greenis 料理機：**
```
功能一：切菜 — 切末、剁泥、碎丁，粗細大小隨心所欲
功能二：絞肉 — 肥瘦比例｜絞肉粗細｜客製化
功能三：揉麵 — 大扭力馬達，攪打勁道好口感
...
功能九：副食品 — 從烹煮到打碎，一氣呵成
```

**JMGO 投影機：**
```
＃1 4K UHD 極致畫質
＃2 3000 ANSI 流明——就算白天不拉窗簾也超清
＃3 超絕顯色——色域 BT2020 area 110% 全覆蓋
＃4 360°天幕雲台，自由開火！
```

### 4-3｜每個功能段落的內部結構

```
圖像化大標（橘色）：用消費者聽得懂的語言說出好處
  例：「不夠涼叫什麼冷氣？」
  例：「20Bar專業高壓——義式咖啡機的現萃實力」

圖像化副標（藍色）：補充具體數據或畫面
  例：「風口實測 11°C」
  例：「0.000001 秒延遲，比一般快 1 萬倍」

內文（灰色）：解釋原理或補充細節（2-3 行，不超過 50 字）
  例：「奈米光合觸媒在紫外光照射下能將空氣解離成具有殺菌能力的多種光合淨化因子」
```

### 4-4｜操作步驟（簡化使用門檻）

讓消費者覺得「這很簡單我做得到」：

**OutIn：**
```
Step 1：放入咖啡膠囊 / 添加咖啡粉
Step 2：加水（冷熱皆可）
Step 3：一鍵萃取 Espresso
```

**Greenis：**
```
Step 1：放入食材和調味料
Step 2：點選並開始料理行程
Step 3：完成烹調，享用美食
```

**SANSUI 冷氣：**
```
Step 1：插上電源
Step 2：一鍵開機
Step 3：放置身旁直吹 / 安裝風管集中降溫
```

**規律：永遠是 3 步驟。**

## ５｜What — 技術 / 材料 / 規格

**目的：滿足「已經心動，但需要理性支撐」的消費者。**

### 5-1｜核心技術深入（通常 1-2 個最重要的技術）

不是列規格，而是把技術「翻譯」成消費者聽得懂的好處：

**ECOHEAL 的 PHIT 技術：**
```
大標：把污染變成水、二氧化碳的科技魔法
副標：PHIT 光合離子化技術
內文：奈米光合觸媒在紫外光的照射下能將空氣解離成...
背景：原先只用在大型醫療機構，KNOT 把商用技術濃縮至家用尺寸
```

**MONACOOK 的不沾塗層：**
```
大標：新一代陶瓷塗層——韓國 7 層強化不沾
對比：他牌使用一個月不沾效果下降 vs MONACOOK 半年依然強力不沾
數據：100,000 次耐磨認證
安心：不含 PFOA / PFOS / 鐵氟龍
```

### 5-2｜硬規格表

放在接近頁面底部，給需要仔細比較的消費者：
- 尺寸、重量、電壓、材質、功率、容量
- 通常用表格呈現
- 搭配產品示意圖標示尺寸

## ６｜Trust — 信任建立

**目的：消除最後的猶豫。**

### 6-1｜與競品 / 他牌比較表

幾乎每份範例都有一張比較表，選 2-3 個競品對比：

**比較維度通常包含：**
價格、核心規格、獨特功能、使用便利性、耗材成本

**呈現方式：**
自己那欄永遠最突出（粗體、✓ 符號、數字領先）

範例：Neabot vs 石頭 vs ECOVACS vs 小米
範例：POIEMA vs 飛XX vs G-Plxx
範例：DIKE 雪泥機 vs 果汁機 vs 冰淇淋機

### 6-2｜認證 / 獎項 / 實測報告

- SGS 認證、BSMI、NCC
- 紅點設計獎、iF 設計獎、VGP、金點設計獎
- 實驗室報告（ECOHEAL 的除臭實驗數據表）
- 暴力測試影片（VELO 行李箱耐用度測試）

### 6-3｜品牌 / 團隊故事

簡短說明「我們是誰，為什麼值得信任」：
- 悠合：「水族顧問 x 工業設計，15 年養魚經驗達人打造」
- WONDER：「旺德電通在台經營超過 35 年，翻譯產品累積銷售超過十萬台」
- POIEMA：「淨化領導品牌，在台深耕 8 年」

### 6-4｜保固 / 售後承諾

- 「X 年在地保固」
- 「拒當售後孤兒」（JMGO 用語）
- 「完善客服團隊，LINE、電話諮詢，專人到府收送」

## ７｜Reward — 方案 / 價格 / 行動呼籲

**目的：把心動轉換成下單。**

### 7-1｜方案架構（募資常見三層）

```
限量超早鳥：＄___（通常最低價，限量）
募資早鳥：＄___
募資優惠價 / 嘖嘖專屬：＄___
未來市售價：＄___（製造落差感）
```

### 7-2｜方案內容物清單

每個方案列出包含什麼，通常用表格或條列：
- 主機 x1
- 配件 A x1
- 配件 B x1
- 募資限定加贈 XXX

### 7-3｜加購配件區

獨立一區展示可加購的配件，每個配件一句話說明用途：
- OutIn：專業版萃取組、金屬萃取立架、硬殼探險包
- VELO：四格收納方包、電腦收納包、充氣頸枕、行李吊牌
- JMGO：瞭望支架、頂掛垂降、壁掛平台、投影布幕

### 7-4｜分期資訊（如適用）

「嘖嘖募資刷卡 3/6 期 0 利率」

## ８｜補充模組（視產品需要選用）

### 8-A｜生活情境總覽

當產品可用場景多元時，用一組「場景名 + 解決什麼」快速掃過：

**ECOHEAL：**
- 玄關大門｜外在污染、病毒
- 新家裝潢｜甲醛、有機揮發
- 嬰幼兒房｜外在污染、病毒
- 廚房｜油煙、食物腐敗味
- 寵物｜便溺臭味

**POIEMA：**
- 冰箱冷藏｜炎炎夏日隨時有純淨冰水
- 招待客人｜不用乾等
- 料理下廚｜上好水質是料理的基石
- 臥室書房｜不用頻繁起身倒水

### 8-B｜安全設計

獨立段落強調安全（尤其家電、廚房類）：
- Greenis：自動斷電、機身鎖定、防滑矽膠墊
- SANSUI：低壓監測、過流監測、高溫監測、傾倒平衡監測
- POIEMA：兒童安全鎖

### 8-C｜清潔 / 維護便利性

消費者買家電最怕的就是「後續很麻煩」：
- Greenis：「一鍵清洗，清潔同樣不沾手」
- DIKE：「不用手洗！一鍵自動清洗」
- MONACOOK：「全鍋可拆洗、可進洗碗機」
- POIEMA：「免手動，智慧全機自動清洗」

### 8-D｜顏色 / 外觀選擇

通常在接近尾端，展示色系選項：
- OutIn：森林綠｜湖水青｜銀河灰｜晨曦白｜莓果紅
- MONACOOK：奶茶棕｜櫻花粉｜抹茶綠
- VELO：率性黑｜逍遙銀
- 悠合魚缸：上蓋飾板顏色自由選擇

### 8-E｜配件一覽

把所有配件用圖 + 名稱列出，讓消費者知道「買到什麼」：
- 悠合魚缸列出 18 項產品內容物
- Hug 貓跳台列出入門款 vs 全配款的配件差異

## ９｜文案層級系統（視覺標記規則）

所有範例都遵循一致的文字層級：

| 層級 | 視覺標記 | 用途 | 字數建議 |
|------|----------|------|----------|
| **圖像化大標** | 橘色粗體 | 段落主題，用消費者語言 | 5-15 字 |
| **圖像化副標** | 藍色粗體 | 補充大標，加入數據或畫面 | 8-20 字 |
| **內文** | 灰色小字 | 解釋原理或補充細節 | 每段不超過 50 字 |
| **圖上文字** | 藍色 | 直接壓在圖片上的文字 | 越短越好 |

**大標的語言風格：**
- 不是在描述功能，是在描述「擁有後的感覺」
- 用消費者的語言，不用工程師的語言
- 範例對比：
  - ✗「R290 環保製冷壓縮機」（這是副標層級的補充）
  - ✓「不夠涼叫什麼冷氣？SANSUI 酷涼關鍵核心」（這才是大標）

## 10｜完整段落順序模板

將以上所有模組串成一份完整的頁面：

```
━━━ 策略備忘（不出現在頁面上）━━━
產品定位 / 市場定位 / 傳播定位（核心→中層→表層）
段落結構矩陣

━━━ 頁面正式開始 ━━━

【1】Opening
  ├─ 主視覺 + 產品名 + 核心 Slogan
  ├─ 社會證明（募資金額 / 銷售數字 / 國際成績）
  └─ KOL 推薦（選用）

【2】Why — 問題意識
  ├─ 痛點列舉（3-4 個生活場景）
  ├─ 反問質疑 / 現有方案不足
  └─ 結論轉折：「你值得更好的」

【3】特色速覽
  └─ 6-8 格特色表（icon + 關鍵字）

【4】How — 場景 + 功能展開（頁面最長區段）
  ├─ 場景總覽（想怎麼用就怎麼用）
  ├─ 功能逐條展開（每條 = 大標 + 副標 + 內文 + 圖）
  ├─ 操作步驟（永遠 3 步）
  └─ 額外場景延伸

【5】What — 技術 / 材料深入
  ├─ 核心技術翻譯（1-2 個最重要的）
  └─ 硬規格表

【6】補充模組（視需要選用）
  ├─ 安全設計
  ├─ 清潔維護便利性
  ├─ 顏色外觀選擇
  └─ 配件一覽

【7】Trust — 信任建立
  ├─ 與競品比較表
  ├─ 認證 / 獎項 / 實測
  ├─ 品牌團隊故事
  └─ 保固售後

【8】Reward — 方案價格
  ├─ 方案架構（超早鳥 / 早鳥 / 優惠）
  ├─ 內容物清單
  ├─ 加購配件
  └─ 分期資訊

【尾】質感生活收尾圖
  └─ 一張美美的情境圖 + 一句收尾語
```

## 11｜各品類的「核心語感差異」速查

| 品類 | Why 段的切入角度 | How 段的語感 | 大標風格 |
|------|-----------------|-------------|----------|
| **3C 硬體** | 你現在的設備讓你很委屈 | 場景 > 規格，把數字變成「你的生活會怎樣」 | 「想怎麼看就怎麼看」 |
| **廚房料理** | 列舉廚房困擾（同質化高，用數量取勝） | 每個功能配一道菜的照片 | 「一台抵多台，聰明料理免動手」 |
| **咖啡** | 現有方案都不夠好（雙線：門檻 + 品味） | 專業數據搭配戶外浪漫場景 | 「擁抱曠野，現萃入喉」 |
| **家電清潔** | 先讓人覺得「現在有問題」 | 技術翻譯 + 實驗數據 + 比較表 | 「除味不能憑感覺，得要趕盡殺絕」 |
| **寵物** | 不用說服邏輯，說出飼主的愛與愧疚 | 站在寵物角度描述功能 | 「喵臨天下！讓貓皇有回家的感覺」 |
| **影音攝影** | 你值得更好的視聽體驗 | 規格＋「有了它你能做到什麼」 | 「讓你穿越進遊戲的眼鏡」 |
| **出行交通** | 挑戰現有習慣的不合理 | 重塑「你的移動/旅行方式」 | 「你家到底有多少行李箱？」 |
| **小眾興趣** | 對的人聽到會心一笑的共鳴 | 圈內語言 + 專業細節 | 「人呼吸空氣、魚仰賴活水」 |

## 12｜執行注意事項

1. **圖寬 697px，高不限，單張 ≤ 2MB**（募資平台限制）
2. **相片盡量實品拍攝，少用模擬圖**
3. **文字與畫面是「一」**——寫文案時就要決定這張圖該呈現什麼感覺
4. **手機閱讀為主**——圖上文字不得小於 16 級
5. **紅色字 = 需向品牌方確認的數據**
6. **附註設計/商攝建議僅供參考，以設計團隊想法為主**
