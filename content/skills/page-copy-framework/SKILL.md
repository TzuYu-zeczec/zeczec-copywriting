# 募資頁面文案框架

## 使用流程

當使用者要求撰寫募資／銷售頁面文案時，按以下順序執行：

### Step 1：套用完整框架
以下已自動載入從 15 份實戰範例歸納的完整頁面結構框架（full-framework.md），請直接依照框架執行。

### Step 2：同時套用風格指南
框架管「什麼段落放在哪」，風格指南管「每一句話怎麼寫」，兩者缺一不可。如果風格指南內容已載入（full-style-guide.md），請同時遵循。

### Step 3：確認產品資料
在動筆前，確認手上有以下素材：
- 產品規格 / 功能清單
- 競品資訊（價格、功能對比）
- 受眾輪廓（如果有 persona-matrix 產出的矩陣更好）
- 品牌方提供的素材（認證、KOL、社會證明）

### Step 4：先寫策略備忘
按框架 Section 0 的格式，先完成：
1. **桂氏三角**（產品定位 / 市場定位 / 傳播定位三層）
2. **段落結構矩陣**（確保每個賣點被分配到正確段落）

### Step 5：按框架順序撰寫頁面
```
策略備忘（不出現在頁面上）
  → Opening（主視覺 + slogan + 社會證明）
  → Why（痛點 + 現有方案打臉 + 橋接句）
  → 特色速覽（6-8 格表）
  → How（場景 + 功能展開 + 操作步驟）
  → What（核心技術翻譯 + 硬規格表）
  → 補充模組（安全/清潔/顏色/配件，視需要選用）
  → Trust（競品比較表 + 認證 + 品牌故事 + 保固）
  → Reward（方案架構 + 內容物 + 加購 + 分期）
  → 收尾（情境圖 + 收尾語）
```

### Step 6：文案層級標記
所有文案必須標記三層視覺層級：
- **橘色大標**：段落主題，用消費者語言（5-15 字）
- **藍色副標**：補充數據或畫面（8-20 字）
- **灰色內文**：解釋原理或細節（每段不超過 50 字）
- **紅色字**：需向品牌方確認的資訊

### 執行原則
- **先做多再刪減**——AI 應先多產內容，由使用者決定刪減，不自行判斷刪什麼
- **文字與畫面是「一」**——寫文案時同步給出圖片建議
- **手機閱讀為主**——圖上文字不小於 16 級
- 圖寬 697px，高不限，單張 ≤ 2MB（募資平台限制）

詳細的段落結構、範例、品類語感差異，已自動載入於完整框架內容中，請直接參照。
