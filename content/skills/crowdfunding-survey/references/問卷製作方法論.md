# 募資問卷製作方法論

## 概述

募資問卷不只是「問問題」，而是一場迷你版的銷售頁體驗。每一題都在做產品溝通——星級題像 Landing Page 的 Hero Section 負責打主力賣點，多選題負責補完次要特色並收集偏好數據。問卷的目標是同時完成「市場前測」和「預熱宣傳」兩件事。

### 平台選擇

本方法論支援兩種問卷平台，開始製作前必須先確認平台：

| 平台 | 體驗特性 | 圖片規格 | 適用場景 |
|------|---------|---------|---------|
| **SurveyCake** | 長頁滾動，題目全部在同一頁 | 1200×600 / 800×600 / 1080×1080 | 功能複雜、需要大量說明的產品 |
| **Typeform** | 一次一張圖卡，逐步沉浸式體驗 | 1080×1520（直式） | 品牌感強、需要帶著填答者走的產品 |

以下方法論以 SurveyCake 為主軸說明。Typeform 路徑的差異（圖片版面解剖、銜接按鈕、黃金排序）請參閱 `Typeform募資問卷格式規範.md`。

---

## 一、流程總覽

整體分為五個階段，依序執行：

```
Step 1  產品資料拆解 → 拉出主力特色、賣點、策略
Step 2  功能分類分群 → 依情境／受眾／特色類別歸組
Step 3  題型分配      → 判斷星級題 vs 多選題，排定流程
Step 4  問卷文案撰寫  → Opening + 每題主標副標敘述 + 選項
Step 5  配圖設計稿    → 依規格產出所有圖片設計稿
```

---

## 二、Step 1：產品資料拆解

從產品資料（PDF、xlsx、圖片、文字）中提取以下資訊：

| 項目 | 說明 |
|------|------|
| USP（獨特賣點） | 市場上只有這個產品做得到的事 |
| KSP（關鍵賣點） | 3-5 個主力賣點，各自值得獨立講 |
| 背景議題／核心痛點 | 消費者目前遇到的困擾，產品能解決的 |
| 最佳使用情境 | 2-3 個最能打動人的使用場景 |
| 關鍵規格 | 技術規格中消費者能感受到差異的 |
| 其他規格 | 有加分但不是主力的特色 |
| 競品資訊 | 競品做不到什麼、價格帶在哪 |

---

## 三、Step 2：功能分類分群

將拆解出來的特色，依照以下維度歸組：

### 分類方式

- **依情境**：在某某情境下，這些功能好用（例：回家場景、訪客場景、出門場景）
- **依受眾**：針對某某人，這些功能最相關（例：給長輩用的、給小孩用的）
- **依特色類別**：同類型的功能放一起（例：安全性、便利性、智慧連動）

### 分類原則

- 每一組要有 4 個以上的選項，才值得做成一題多選
- 主力賣點（KSP）不放在多選裡，獨立拉出做星級題
- 次要但加在一起有分量的特色，歸類成「貼心設計」多選

---

## 四、Step 3：題型分配

### 兩大題型

#### 星級題

用於宣傳主力賣點。像 Landing Page 的概念，用吸睛的標題＋圖片帶出特色。

**標準架構**：
1. 主標語（一句話打動人）
2. 副標語（補充說明主標）
3. 配圖（800x600）
4. 敘述文字（2-4 行，講清楚這個特色的好處）
5. 星級量表（1-7 星）

**使用時機**：這個特色有獨立拉篇幅出來的價值，尤其是主要賣點。

#### 多選題（帶圖）

有四種使用情境：

| 情境 | 說明 | 範例 |
|------|------|------|
| 1. 歸類次要特色 | 完整方便分類的特色，4 個以上、非主力賣點 | 「安全鎖」「APP 監控」「認證」→ 安全性 |
| 2. 選使用情境 | 同一個功能的多種使用場景 | 「與音響連動」「與燈光連動」「與冷氣連動」 |
| 3. 選規格 | 選顏色、選配件、選方案 | 「這些顏色你最想要哪種？」 |
| 4. 問痛點 | 放在問卷最前面，市場教育用 | 「你是否遇過以下困擾？」 |

**多選題限選規則**：設定最多選 2-3 個，避免全勾導致數據失真。

### 判斷邏輯 Q&A

**Q：如何判斷該用星級還是多選？**
A：判斷這個特點有沒有獨立拉篇幅出來的價值。如果有（甚至是主要賣點），就拉出來做星級題。

**Q：多選題要不要在選項之外，在題目上加敘述與圖？**
A：如果這個特色是大重點，就可以在題目處加圖片和敘述。

**Q：星級題要做哪一種圖、要用幾張圖？**
A：跟電商銷售頁的邏輯一樣——產品要展示功能用示意圖，要展示質感用實拍圖，要展示對比用比較圖。

**Q：星級題跟多選題能講同一件事嗎？**
A：可以，互相搭配。實務上就是星級題講完大賣點之後，接續的多選題讓你選該賣點的使用情境。

## 五、Step 4：問卷文案撰寫

### 常見結構（10 題制，15 題以內）

```
一、主標題／主視覺圖
二、Opening 開場（100-150 字）／特色簡介圖／好禮誘因圖
三、（若需市場教育）痛點多選題
四、星級題 1 — 主力賣點 #1
五、星級題 2 — 主力賣點 #2
   （可接多選題：該賣點的使用情境）
六、星級題 3 — 主力賣點 #3
   （可接多選題：該賣點的使用情境）
七、多選題 — 貼心特色／安全設計
八、購買意願星級題（含價格方案圖）
九、Email
十、手機
十一、開放題 — 請留下建議
十二、送出 → 跳轉 LINE 參加抽獎
```

### Opening 寫法

- 約 100-150 字
- 寫產品概述，列出 X 大產品特點，或凸顯銷售成績
- 搭配「格狀特色簡介圖」（6 宮格）
- 標配好禮誘因區塊：

```
即將登上嘖嘖募資
2 分鐘填寫問卷 享 3 大好禮
$OOO 元專屬折扣碼｜開賣首發通知｜好禮抽獎機會
```

### 星級題文案寫法

- **主標語**：一句話，口語化，傳遞感受而非規格
- **副標語**：補充規格或技術名詞，用「｜」分隔
- **敘述文字**：2-4 行，每行講一個利益點，從消費者角度出發
- **星級量表**：說明文字 + 1-7 星（7 星為最高）

### 多選題文案寫法

- **題目**：一句話問清楚在選什麼
- **副標**：標示限選數量（最多選 2-3 個）
- **選項格式**：選項名稱 + 一句話說明好處
- **選項配圖**：1080x1080，每個選項一張

## 六、Step 5：互動式問卷 HTML 設計稿

### 輸出格式

SurveyCake 路徑的設計稿統一以「全螢幕逐題滑動式互動 HTML」呈現。單一 .html 檔案，CSS + JS 全部內嵌，可在瀏覽器中直接操作體驗完整問卷流程。

完整規範見 `SurveyCake互動式問卷HTML格式規範.md`，參考模板見 `Breo_iNeck_Air2_前測問卷.html`。

### 核心特性

- 每題一個全螢幕 slide，淡入淡出 + 垂直位移動畫
- 固定頂部進度條 + 固定右側導航圓點
- 鍵盤操作（Enter / ↑↓）+ 手機觸控滑動
- CSS Variables 管理品牌色系，每份問卷只需替換三個色值

### 六種 Slide 元件

| 元件 | 用於 |
|------|------|
| Opening 封面 | 品牌名、產品名、主標語、6 宮格特色、好禮誘因 |
| 星級題（sp-card） | 賣點卡片（badge + 主標 + 說明 + 規格數據）+ 7 星評分 |
| 多選題（choice-grid） | 打勾選項列表（主文字 + 副文字）+ 限選提示 |
| 購買意願（price-card） | 價格卡片（原價刪除線、早鳥價、加碼優惠）+ 7 星評分 |
| 輸入題 | Email / 手機 / 開放題 |
| 感謝頁 | 感謝文字 + LINE 官帳按鈕 |

### 產出步驟

1. 從範例模板複製 CSS 設計系統與 JS 互動邏輯
2. 替換品牌色（`--brand` / `--brand-dark` / `--brand-light`）
3. 依問卷架構逐題建立 slide HTML
4. 修改 JS 中的 `totalSlides` 數值
5. 瀏覽器全螢幕預覽確認體驗流暢

## 七、自我檢查清單

完成問卷後，逐項確認：

1. 總題數是否在 15 題以內
2. 痛點多選題是否放在星級題之前（先激發需求再回應）
3. 星級題與多選題的搭配是否合理（大賣點用星級，次要特色用多選）
4. 多選題是否都設了限選數量（最多 2-3 個）
5. Opening 是否在 100-150 字以內
6. 好禮誘因是否完整（折扣碼＋首發通知＋抽獎）
7. 購買意願星級題是否含價格資訊
8. Email / 手機 / 開放題是否都有
9. 送出後是否有跳轉 LINE 的引導
10. 互動式 HTML 是否能在瀏覽器中完整操作（每題切換、星級點擊、多選限選）
11. HTML 品牌色是否已替換為該產品的品牌色系
12. JS 的 totalSlides 數值是否正確

## 八、Typeform 路徑補充

若使用 Typeform 平台，以下規則取代或補充上方 SurveyCake 的對應段落：

### 結構差異

- 不使用星級題穿插多選題的組合，改為「圖片卡片＋問題題組」交錯排列
- 所有圖片統一為 **1080 × 1520px** 直式卡片
- 每張圖片卡片之間需設計**銜接按鈕文字**（懸念式問句，8-15 字）

### 特色圖排序（黃金順序）

| 順序 | 圖片主題 | 邏輯 |
|-----|---------|------|
| 第 1 張 | 核心差異化賣點 | 先建立「為什麼是這個」 |
| 第 2 張 | 感官體驗 / 實際效果 | 視覺驗證 |
| 第 3 張 | 獨家 / 首創 / 稀缺性 | 強化信念 |
| 第 4 張 | 操控便利性 / App | 消除疑慮 |
| 第 5 張 | 內容生態 / 長期價值 | 延伸想像 |
| 第 6 張 | 附加功能 / 驚喜彩蛋 | 最後一推 |

### 圖片版面三區結構

每張 1080×1520 圖片分為三區：
- **上方 55-60%**：情境畫面（人＋產品使用情境）
- **中間**：主標題（大字、字間距寬）＋副標題
- **下方 25-30%**：特色列點區（版型 A 三欄 / 版型 B 2×2 / 版型 C Before-After）

### 問題題組簡化

Typeform 路徑的問題數量較少（標準 5-6 題），固定結構為：
Q1 痛點多選 → Q2 情境偏好單選 → Q3 購買意願星級 → Q4 Email → Q5 手機 → Q6 開放題

完整規範請參閱 `Typeform募資問卷格式規範.md`。
