# Typeform 募資問卷格式規範

> 適用於群眾募資前測問卷，以 1080 × 1520px 直式圖片為主體，問題穿插其中。

---

## 一、整體流程架構

```
封面頁（Opening）
  ↓ [銜接按鈕 → 懸念文字]
Q1 — 痛點確認（多選題）
  ↓ [銜接按鈕]
特色圖 ① 核心差異化賣點（最強、最獨特）
  ↓ [銜接按鈕]
特色圖 ② 第二賣點
  ↓ [銜接按鈕]
特色圖 ③ 第三賣點
  ↓ [銜接按鈕]
特色圖 ④ ~ ⑥（依產品複雜度調整）
  ↓ [銜接按鈕]
Q2 — 使用情境 / 偏好（單選題）
  ↓ [銜接按鈕]
Q3 — 購買意願星級題（1~7 顆星，附價格）
  ↓ [銜接按鈕]
Q4 — Email（必填）
  ↓ [銜接按鈕]
Q5 — 手機號碼（選填）
  ↓ [銜接按鈕]
Q6 — 開放意見（選填）
  ↓
感謝頁（結束 / 跳轉）
```

**總頁數參考**

| 問卷長度 | 圖片張數 | 問題數 | 適用 |
|---------|---------|-------|------|
| 精簡版 | 3–4 張 | 3–4 題 | 粉絲已熟悉產品 |
| 標準版 | 5–6 張 | 5–6 題 | 一般前測問卷 |
| 完整版 | 7–8 張 | 6–8 題 | 功能複雜的產品 |

## 二、圖片卡片版面解剖（1080 × 1520px）

每張圖分為三個垂直區域：

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│          情境畫面區域              │  ← 約 55–60% 高度
│      （人 ＋ 產品使用情境）         │
│                                   │
│                                   │
├──── ─ ─ 撕裂紙紋過渡線 ─ ─ ────────┤  ← 設計分隔效果
│                                   │
│      【主標題】（大字、字間距寬）    │  ← 中間標題區
│      【副標題】（小字補充說明）     │
│                                   │
├───────────────────────────────────┤
│                                   │
│      特色列點區                   │  ← 下方 25–30%
│  （標籤組合，見版型 A / B / C）    │
│                                   │
│  底部總結一行（橫排字間距大）       │  ← 選用
└───────────────────────────────────┘
```

---

### 區域①：情境畫面（上方）

- 使用**真實使用情境照**（人＋產品），避免白底產品單圖
- 強調**生活感、空間感**，讓受訪者代入場景
- 第一張（封面）可使用 Before/After 對比圖
- 圖片底部加**撕裂紙紋過渡**，讓圖與文字區自然銜接

---

### 區域②：標題區（中間）

**主標題** — 2–3 行，字大，字距寬，三種語氣：

| 語氣 | 範例 |
|-----|------|
| 問句感（引發好奇） | 「這是真的畫布嗎？」 |
| 驚嘆感（強調唯一） | 「市面唯一！首創無線設計」 |
| 結論感（直給答案） | 「首創無線隨掛 秒速更換畫作」 |

**副標題** — 補充說明，通常帶數字或科技詞彙增加可信度
> 例：「採用最新 Spectra 6 全彩 E-Ink 科技」

**底部一行** — 橫排字間距加大的總結標語（選用）
> 例：「無 線 設 計 × 超 長 續 航 力」

---

### 區域③：特色列點區（下方）

三種常見版型，依特色數量選擇：

**版型 A — 3 欄橫排**（適合並列 3 個特色）
```
[ ✓ 特色A ]   [ ✓ 特色B ]   [ ✓ 特色C ]
   補充說明       補充說明       補充說明
```
> 範例：色彩飽滿自然 ／ 無眩光無背光 ／ 如同美術館真跡

**版型 B — 2×2 格**（適合 4 個功能）
```
[ 功能 A ─────── ]   [ 功能 B ─────── ]
  補充說明               補充說明

[ 功能 C ─────── ]   [ 功能 D ─────── ]
  補充說明               補充說明
```
> 範例：全家共用 ／ 隨時更換 ／ 資訊安全 ／ 居家智慧助理

**版型 C — Before / After 對比**（適合封面或痛點圖）
```
[ Before ─────── ]   [ 品牌名 ────── ]
  問題描述               解決方案
```
> 範例：「實體畫作收藏不易 空間、預算都是限制」vs「一框收藏上萬幅畫 無線設計隨心展示」

## 三、銜接文字按鈕規範

每張圖片與下一頁之間的按鈕，是驅動受訪者繼續滑動的誘因。

**寫作原則**：
- 帶問句或懸念，點出下一頁的主題
- 讓受訪者感到「對，我想知道這個問題的答案」
- **絕對不要**只寫「下一頁」「繼續」

**BLOOMIN8 範例對照**：

| 按鈕文字 | 對應下一頁內容 |
|--------|-------------|
| 「這些藝術品，該放哪裡呢？」 | 無線設計 / 擺放自由 |
| 「這個畫作看膩了怎麼辦？」 | 一鍵換畫功能 |
| 「不知道要放什麼畫怎麼辦？」 | 精選藝廊 / AI 生成 |
| 「除了展示，還有其他功能嗎？」 | 智慧功能（天氣、行事曆）|
| 「還想知道更多！」 | 使用情境頁 |
| 「有沒有更多的使用方式？」 | 問題題組 |

## 四、問題題型規範

### Q1 — 痛點確認（多選題）

- **位置**：問卷最前面，封面之後
- **目的**：讓受訪者先「對號入座」，心理上認同問題存在
- **格式**：「類別｜具體情境說明」
- **數量**：4–6 個選項
- **提示文字**：「Choose as many as you like」

```
【標題】帶感嘆或疑問句，點出痛點場景
【副標】以下哪些狀況最常讓你感到困擾？

選項：
A | 類別一 — 具體說明
B | 類別二 — 具體說明
C | 類別三 — 具體說明
D | 類別四 — 具體說明
E | 類別五 — 具體說明
```

---

### Q2 — 使用情境 / 偏好（單選題）

- **位置**：特色圖之後
- **目的**：了解受眾使用場景，同時強化使用想像
- **格式**：情境場景描述
- **數量**：4–5 個選項

---

### Q3 — 購買意願星級題（1~7 顆星）

- **位置**：所有特色圖之後，名單收集之前
- **必須**：先展示產品圖 + 早鳥價格，再接星級題
- **標示**：「非常不想要 = 1 顆星；非常想要 = 7 顆星」
- **變形**：每個功能也可各配一題星級（功能吸引力調查）

```
【產品圖 + 價格標示區】
標題：XXXXX 早鳥首發價 $XXXX
說明：一句話產品描述

請問若價格如上所述，你會想要入手嗎？
（非常不想要 = 1 顆星；非常想要 = 7 顆星）
☆ ☆ ☆ ☆ ☆ ☆ ☆
```

---

### Q4 — Email（必填）

- 搭配明確誘因降低填寫阻力
- 誘因建議包含：折扣碼 ＋ 第一手通知 ＋ 稀缺限定感

```
📩 留下常用 Email，搶先獲得：
✅ 早鳥獨家折扣碼
✅ 開賣第一手通知
✅ 限量早鳥搶購資格

我們還會寄發專屬活動通知，
包括加碼好禮、秘密抽獎，都只限問卷填答者！

[name@example.com                    ]
```

---

### Q5 — 手機號碼（選填）

- 說明用途，強調「非必填」降低阻力

```
📱（非必填）不常使用信箱？
留下手機，我們將在開賣當天以簡訊第一時間通知你！

[0912 345 678                        ]
```

---

### Q6 — 開放意見（選填）

- 放最後，降低填答壓力
- 用於質性研究，收集未預期的消費者語言

```
對 [產品名] 有什麼期待、想法或建議？
我們都想聽！（選填）

[                                    ]
[                                    ]
```

## 五、特色圖片的內容排序原則

**黃金順序：從差異化往外展開**

| 順序 | 圖片主題 | 邏輯 |
|-----|---------|------|
| 第 1 張 | 核心差異化賣點（vs 競品最大差距） | 先建立「為什麼是這個」的理由 |
| 第 2 張 | 感官體驗 / 實際效果 | 「它真的做得到嗎？」的視覺驗證 |
| 第 3 張 | 獨家 / 首創 / 稀缺性 | 強化「只有這裡有」的信念 |
| 第 4 張 | 操控便利性 / App / 軟體 | 「用起來會不會很麻煩？」的消除疑慮 |
| 第 5 張 | 內容生態 / 長期使用價值 | 「買了之後還能做什麼？」的延伸 |
| 第 6 張 | 附加功能 / 驚喜彩蛋 | 讓人覺得「超值」的最後一推 |

**每張圖解決一個消費者可能會問的問題**，圖的主題就是那個問題的答案。

## 六、整份問卷設計流程（製作步驟）

```
Step 1｜產品定位與策略制定
  → 確認核心差異化（vs 競品）
  → 確認目標受眾的最大痛點
  → 確認最強的 1–2 個賣點

Step 2｜把所有特點攤開來看
  → 列出產品所有功能 / 特色
  → 依重要程度排序
  → 考慮相鄰特點之間的邏輯銜接

Step 3｜規劃圖片張數與分配
  → 確定要做幾張圖（標準 5–6 張）
  → 每張圖對應一個核心訴求
  → 設計銜接按鈕文字（帶懸念的問句）

Step 4｜逐張撰寫圖片內容
  → 情境畫面描述（給設計師的素材方向）
  → 主標題 + 副標題
  → 下方特色列點（版型 A / B / C）
  → 底部總結一行

Step 5｜設計問題題組
  → Q1 痛點（多選）
  → Q2 情境偏好（單選）
  → Q3 購買意願星級（帶價格）
  → Q4 Email（必填）
  → Q5 手機（選填）
  → Q6 開放意見（選填）

Step 6｜Typeform 建置
  → 上傳圖片作為「圖片卡片」（Statement 類型）
  → 設定每張圖的銜接按鈕文字
  → 插入問題題組
  → 設定結尾跳轉
```
