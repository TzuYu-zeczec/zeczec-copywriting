# 受眾輪廓標籤矩陣 Skill

每次執行前請先完整讀完這份 SKILL.md，理解框架後再開始工作。

---

## 零、Meta 廣告刊登政策合規要求 ⚠️

**受眾輪廓將用於 Meta 廣告平台，所有生成內容必須嚴格遵守以下規範。**

### 0.1 禁止暗示個人特質（個人隱私保護）

廣告文案（Hook、CTA、輪廓敘述）**不得**：
- 直接或間接指出受眾的種族、民族、宗教信仰、年齡、性傾向、性別認同、身心障礙、健康狀況、財務困難、投票狀況、工會會員身分、犯罪紀錄
- 使用「你是 XX 嗎？」「你有 XX 問題嗎？」等句型，暗示受眾具備某項個人特質
- 搭配「您／您的」等代名詞提及個人特質（例：「準備好讓您的外表更年輕了嗎？」❌）

廣告文案**可以**：
- 泛指群體特質，不針對個人（「給忙碌的家長」✅）
- 描述產品優點與使用情境，而非受眾狀態（「讓通勤更輕鬆」✅）
- 使用情境場景描述（「每天通勤 1 小時以上的上班族」✅）

**合規對照速查：**

| ❌ 違規（禁用） | ✅ 合規（應用） |
|---|---|
| 「你有糖尿病嗎？」 | 「全新糖尿病管理方案」 |
| 「認識其他老年人」 | 「認識年長人士」 |
| 「你是同志嗎？」 | 「亞特蘭提斯男同志郵輪之旅」 |
| 「你破產了嗎？」 | 「財務規劃入門服務」 |
| 「準備好讓外表更年輕了嗎？」 | 「全新抗老乳霜，煥發肌膚光彩」 |
| 「你有憂鬱症嗎？」 | 「憂鬱症諮詢服務」 |
| 「認識其他佛教徒」 | 「和單身的佛教徒約會」 |

### 0.2 禁止成人裸露、性暗示與有害內容

Hook、CTA 文案不得暗示裸露、性行為、色情動作、性暗示姿勢，或任何已知違禁內容。

### 0.3 禁止針對或推廣以下類型

- 危險組織、暴力、仇恨行為
- 詐騙、欺騙行為
- 兒童安全相關的任何危害
- 錯誤資訊的傳播

### 0.4 標籤合規性要求

③ 碎片化標籤：
- 行為與興趣標籤**不得包含敏感個人特質**（健康狀況、財務困難等）
- 人口統計標籤（年齡範圍、性別）可正常使用，但文案中不得指向個人
- 標籤應描述**興趣 / 行為 / 生命事件**，而非個人病症或困境

### 0.5 Hook 與 CTA 文案合規提醒

| ✅ 正確方向 | ❌ 錯誤方向 |
|---|---|
| 聚焦產品優點與情境 | 以受眾缺陷為開場 |
| 「出差忘帶充電器的那一刻」 | 「你老是忘東忘西嗎？」 |
| 「多口輸出，同時充飽所有裝置」 | 「你的電量總是不夠用？」 |
| 「讓通勤時間也能充好電」 | 「你有通勤焦慮嗎？」 |

## 一、輸入處理

產品資訊可能以任何形式提供：

| 格式 | 處理方式 |
|------|---------|
| 純文字訊息 | 直接解析 |
| 圖片（產品照、截圖、說明書） | 視覺辨識，提取品名、功能、賣點、目標客群 |
| xlsx / csv 檔案 | 讀取內容，找出產品名稱、功能描述、價格區間 |
| PDF | 讀取文字層或視覺辨識 |

**最少需要掌握的資訊：**
- 產品名稱與類別
- 核心功能／解決的問題
- 主要賣點（2-5 點）
- 價格區間（若有）
- 已知目標族群（若有，作為推演起點）

如果資訊不足以分析，先問使用者補充，不要憑空猜測。

## 二、受眾推演邏輯

### 2.1 推演框架

從產品的「問題-解法」出發，思考哪些人有這個問題：

1. **核心使用情境**：這個產品在什麼場景下被使用？（通勤、辦公桌、旅行、家庭等）
2. **誰有這個痛點**：對應情境中，哪些人群最可能感受到這個痛點？
3. **購買決策因素**：他們決定購買時最在意什麼？（安全、效率、美觀、CP值、品牌）
4. **媒體使用習慣**：他們在哪裡獲取資訊？（IG、YouTube、PTT、Dcard、媽媽社群）

### 2.2 多維度切割

不要只從「人口統計」切割受眾，要用多個維度交叉：

- **使用場景** × **生命階段**：例如「有幼兒的雙薪家庭 in 租屋套房」
- **職業身份** × **設備生態**：例如「Apple 生態圈重度用戶 in 科技業」
- **旅行頻率** × **消費等級**：例如「月出差 2 次以上的業務主管」
- **興趣社群** × **購買行為**：例如「群眾募資早期支持者 in 生產力工具社群」

### 2.3 輸出數量

- **標準**：8–12 個 persona（確保多元，避免重疊）
- **豐富產品**：最多 15 個
- **每個 persona 必須有明顯區別**：不同痛點、不同媒體接觸點、不同購買動機

## 三、25 個欄位定義

每個 persona 必須填滿以下 25 個欄位。欄位名稱請完全一致（中文字符相同）。

| 分類 | 欄位名稱 | 說明 |
|------|----------|------|
| 識別 | Persona ID | P01, P02 ... 依優先順序排列（購買可能性高→低） |
| 識別 | 代表名稱 | 3-6 字的角色標籤，如「科技效率上班族」 |
| 識別 | 購買機率 | ★★★★★ #1 格式，標示相對優先序 |
| 人口統計 | 年齡設定 | 如 28-40歲 |
| 人口統計 | 性別設定 | 男性為主 / 女性為主 / 男女均等 |
| 人口統計 | 職稱興趣標籤 | Meta 興趣標籤中的職業，如「工程師」「行銷人員」 |
| 人口統計 | 學歷／財務行為 | 如「大學以上學歷」「高收入 8萬+/月」 |
| 人口統計 | 生命週期標籤 | Meta Life Events：近期搬家、新婚、剛訂婚、換新工作、即將過生日、新生兒等。這些受眾處於「主動購買模式」，轉單效率極高，務必填寫 |
| 生活風格 | 生活風格品牌偏好 | 這個人喜歡的品牌 → 對應 Meta 品牌偏好興趣 |
| 生活風格 | 效率／生產力興趣 | Meta 興趣：生產力、GTD、時間管理等 |
| 生活風格 | 價值觀興趣標籤 | Meta 興趣：極簡主義、生活品質、科技早採者等 |
| 心理動機 | 核心購買動機 | 購買「為什麼」：儀式感驅動 / 安全感驅動 / 效率驅動 / 身份認同驅動。非 Meta 標籤，而是策略層分類 |
| 旅行行為 | 移動性行為 | 旅行/移動相關 Meta 標籤。非旅行型產品受眾填「—」 |
| 職業身份 | 商業職場興趣 | Meta 興趣：職場發展、創業精神、商業管理等 |
| 職業身份 | 商務形象興趣 | Meta 興趣：專業形象、高端生活風格、品牌精品等 |
| 科技裝置 | Meta 裝置行為標籤 | Meta 行為：iOS裝置用戶、MacBook用戶、高階手機用戶等 |
| 科技裝置 | 科技產品興趣 | Meta 興趣：Apple、無線充電、3C配件、消費性電子等 |
| 科技裝置 | 科技媒體評測 | 這個人看哪些科技媒體：T客邦、The Verge、YouTube科技評測等 |
| 購買行為 | Meta 購物行為標籤 | Meta 行為：線上購物高頻、群眾募資支持者、高消費購物者等 |
| 購買行為 | 電商平台行為 | 他們在哪裡買：蝦皮、PChome、Amazon、Kickstarter 等 |
| 廣告投放 | 建議廣告版位 | IG Feed、FB Feed、YouTube前貼片、TikTok 等，標注主力 |
| 廣告投放 | KOL 類型 | 這個受眾信任哪種 KOL：科技評測YouTuber、親子生活IG 等 |
| 文案標籤 | Hook 開場關鍵詞 | 廣告前3秒抓住這個人的句子（用具體場景，不用形容詞） |
| 文案標籤 | CTA 賣點關鍵詞 | 點擊廣告的驅動字眼，強調產品對這個人的核心價值 |
| 文案標籤 | 反對意見破解 | 這個人購買前最常說的反對理由 + 如何破解 |

## 四、Meta 廣告標籤填寫原則

**核心原則：** 標籤必須是 Meta Ads Manager 實際收錄的受眾選項，不是描述性文字。

### 4.1 Meta 標籤類型對照

**行為標籤（Behaviors）** — Meta 根據用戶實際行動收集：
- 旅行行為：`頻繁國際旅客 (Frequent international travelers)`、`商務旅行者 (Business travelers)`、`近期出遊者 (Returned from trip 1 week ago)`、`飯店住宿常客`
- 購物行為：`線上購物高頻 (Engaged shoppers)`、`高消費線上購物者 (High-value shoppers)`、`群眾募資支持者 (Crowdfunding backers)`
- 裝置行為：`iOS 裝置用戶 iPhone/iPad`、`MacBook 用戶`、`高階智慧型手機用戶`、`Android 裝置用戶`
- 財務行為：`Higher-income households`、`Apple 裝置付費用戶`

**興趣標籤（Interests）** — Meta 根據用戶按讚/互動的頁面/話題推論：
- 科技：`Apple`、`無線充電 Wireless charging`、`MagSafe`、`消費性電子 Consumer Electronics`
- 職業：`工程師`、`產品經理 PM`、`創業精神 Entrepreneurship`
- 生活風格：`極簡主義 Minimalism`、`生產力 Productivity`、`GTD Getting Things Done`
- 旅行：`商務旅行 Business travel`、`自助旅行`、`機場貴賓室 Airport Lounge`
- 育兒：`親子教養 Parenting`、`嬰幼兒安全 Baby safety`

**人口統計（Demographics）** — Meta 根據用戶資料：
- 學歷：`大學以上學歷`
- 收入：`中高收入 5-8萬/月`、`高收入 8萬+/月`

### 4.2 標籤轉換思路

從受眾的「行為特徵」反推 Meta 可能收錄的標籤：
- 「喜歡桌面整潔」→ `極簡桌面 Desk setup`、`極簡主義 Minimalism`、`居家裝飾 Home Decor`
- 「常出差」→ `頻繁國際旅客`、`商務旅行者`、`飯店住宿常客`（行為）＋ `商務旅行 Business travel`（興趣）
- 「用 Apple 設備」→ `iOS 裝置用戶 iPhone/iPad`（行為）＋ `Apple`（興趣）＋ `Apple 裝置付費用戶`（財務行為）
- 「有幼兒」→ `親子教養 Parenting`、`嬰幼兒安全 Baby safety`（興趣）＋ `Facebook 媽媽社群活躍用戶`（行為）

### 4.3 與產品無關的欄位處理

若某個受眾明顯與某類別無關（例如「電玩宅族」與旅行行為），填入 `["—"]` 即可，不要強行塞標籤。

## 五、② 受眾輪廓總覽 — 敘述格式（雙語）

② 採用「中文 + 英文」雙欄設計。每個 persona 需要：

**中文敘述**（150-250 字）
1. 身份描述（誰是他們？）
2. 生活情境（他們的日常是什麼樣子？）
3. 痛點（這個產品解決他們的什麼問題？）
4. 購買動機（什麼會讓他們掏錢？）
5. 媒體接觸（他們怎麼獲取資訊？）

**英文敘述**（120-200 words）

內容與中文版平行，風格自然流暢（非直譯）。英文版適合用於：
- 外籍合作夥伴、代理商簡報
- 跨境廣告策略對齊
- 媒體購買平台的受眾備忘錄

## 六、執行步驟

### Step 1：整理產品資訊

從輸入中提取以下資訊：
- 產品名稱
- 產品類別
- 核心功能描述
- 關鍵賣點（3-5 個）
- 價格區間
- 認證（若有）
- 已知目標族群描述（若有）

### Step 2：推演受眾清單

先列出所有可能受眾（不超過 20 個候選），然後：
- 篩選有明顯區別的 8-15 個
- 依購買可能性排序（P01 = 最高轉換潛力）
- 為每個命名（3-6 字，中文，代表性強）

### Step 3：填寫 25 欄位矩陣

為每個 persona 填滿第三節定義的 25 個欄位。每個欄位可有多個標籤值。若某欄位與此受眾無關，填「—」。

### Step 4：撰寫敘述文字（雙語）

為每個 persona 撰寫：

**中文敘述**（150-250 字）：
1. 身份描述（誰是他們？）
2. 生活情境（他們的日常是什麼樣子？）
3. 痛點（這個產品解決他們的什麼問題？）
4. 購買動機（什麼會讓他們掏錢？）
5. 媒體接觸（他們怎麼獲取資訊？）

**英文敘述**（120-200 words）：內容與中文版平行，風格自然流暢（非直譯）。

### Step 5：輸出

將所有受眾的完整資料按以下格式輸出：

**輸出結構**：
1. 總覽表：所有 persona 的 ID、代表名稱、購買機率一覽
2. 逐一展開每個 persona 的 25 欄位 + 中英文敘述
3. 標籤複製區：每個 persona 的 Meta 廣告可用標籤，一列一組，方便直接複製到 Meta Ads Manager（排除「購買機率」「Hook 開場關鍵詞」「CTA 賣點關鍵詞」「反對意見破解」四個非 Meta 欄位）

使用者可點擊「存到 Google Sheets」按鈕將結果輸出為格式化試算表。

## 七、品質檢查清單

執行前請確認：
- [ ] 所有 persona 的欄位名稱與第三節定義的 25 個欄位完全一致
- [ ] 每個欄位都已填值（可多個標籤值）
- [ ] 購買機率欄位格式正確：`★★★★★  #1`（兩個空格分隔）
- [ ] 旅行/商務相關欄位若不適用填「—」而非留空
- [ ] 標籤是 Meta 實際標籤而非單純描述文字
- [ ] Hook 開場是「具體場景句子」而非形容詞（例如：「打到最後關頭 Switch 沒電」而非「充電方便」）
- [ ] 標籤複製區 不含「購買機率」「Hook 開場關鍵詞」「CTA 賣點關鍵詞」「反對意見破解」四個欄位
- [ ] **Meta 合規**：所有 Hook、CTA、輪廓敘述均不含暗示個人特質的語句（參見第零節 0.1）
- [ ] **Meta 合規**：標籤欄位不包含以健康狀況、財務困難等敏感特質定義的標籤（參見 0.4）
