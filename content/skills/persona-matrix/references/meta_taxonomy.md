# Meta Ads Manager 受眾標籤分類參考

> 此文件列出 Meta（Facebook/Instagram）廣告系統中常用的受眾標籤，
> 供填寫 FIELD_ORDER 欄位時對應使用。
> 標籤名稱盡量保留英文原名，以便在廣告後台搜尋。

---

## 零、生命週期標籤（Life Events）— 高轉換優先投放

> 生命週期標籤代表用戶正處於「主動購買模式」的人生轉折點，
> 購買意願強、決策速度快，通常是 Meta 廣告 ROAS 最高的受眾類型之一。
> **務必在每個 persona 的「生命週期標籤」欄位認真填寫。**

### 居住／搬家
- `近期搬家 (Recently moved)` ← 剛搬進新家，需要大量添購
- `即將搬家 (About to move)` ← 搬家前已開始購買
- `新租屋族 (New apartment renters)`

### 感情／婚禮
- `剛訂婚 (Recently engaged)` ← 婚禮籌備期購買力爆發
- `新婚 (Newly married)` ← 新家用品採購高峰
- `即將結婚 (Upcoming anniversary/wedding)`
- `穩定交往中 (In a relationship)` ← 適用情侶互送禮物

### 職涯
- `換新工作 (New job)` ← 新環境需要新物件
- `剛畢業 (Recently graduated)` ← 開始獨立生活
- `創業初期 (New business owner)`

### 家庭
- `有新生兒 (New parent)` ← 剛生產，家庭需求激增
- `有6歲以下幼兒的家長 (Parents of young children)`
- `空巢期 (Empty nester)` ← 子女剛離家，家長重新佈置生活

### 生日相關
- `即將過生日 (Upcoming birthday - 30 days)` ← 生日前自購或他人送禮
- `生日月份 (Birthday month)` ← 生日當月，本人或親友高購買意願

### 學業
- `應屆畢業生 (Recent college graduate)` ← 開始獨立生活
- `即將入學 (Back to school)` ← 開學前購買

## 一、行為標籤（Behaviors）

## 三、廣告版位選擇建議

| 受眾特性 | 建議版位 |
|---------|---------|
| 視覺型、女性、生活風格 | Instagram Feed（主力）、Instagram 限動 |
| 商務、35+、決策者 | Facebook Feed（主力）、YouTube 前貼片 |
| B2B、專業形象 | LinkedIn（品牌形象補充） |
| 遊戲、年輕男性 | YouTube 遊戲頻道前貼片 |
| Z世代、創意族群 | TikTok |
| 科技評測受眾 | YouTube 前貼片、YouTube 中貼片 |
| 媽媽社群 | Facebook Feed、Facebook 媽媽社群廣告 |
