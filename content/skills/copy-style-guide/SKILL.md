# 募資頁面文案風格指南

## 使用流程

完整風格指南（full-style-guide.md）已自動載入，請直接套用以下規則。

## 快速參考：核心規則

### 六種大標句型
寫大標時從這六種句型中選擇：
1. **反問刺痛型**：用問句戳中日常不滿（「你家到底有多少行李箱？」）
2. **宣言否定型**：否定現狀，建立新標準（「除味不能憑感覺，得要趕盡殺絕」）
3. **擁有想像型**：想像用了之後的美好（「想怎麼看就怎麼看」）
4. **數字衝擊型**：用極端數字讓人停下來（「募資破億日圓」）
5. **場景召喚型**：直接喊出使用場景（「你也是 OUTDOOR 咖嗎？」）
6. **加法公式型**：用加號等號創造意外組合（「KNOT ＋ 衣櫥 ＝ 電子衣櫥」）

### 黃金法則
- **大標裡永遠不出現技術名詞**，技術放副標或內文
- **副標永遠比大標具體一階**：大標是感受，副標是感受的來源
- **內文像朋友在解釋**，不像說明書在教你
- **每段內文不超過 50 字**（技術翻譯段可放寬至 80-100 字）

### 語氣光譜（隨段落漸變）
```
Opening → 溫暖自信（像老朋友推薦好東西）
Why 痛點 → 同理共鳴（像閨蜜在幫你抱怨）
橋接句 → 篤定有力（像教練說「夠了，交給我」）
功能展開 → 俐落專業（像產品經理在做簡報）
技術深入 → 可靠沈穩（像工程師在跟你保證）
Trust → 溫暖安心（像品牌在承諾「我在這裡」）
方案價格 → 直接乾脆（像店員說「就是這個價」）
```

### 關鍵修辭技法
- **規格翻譯**：規格數字 → 「所以你的生活會怎樣」
- **括號打臉法**：列舉現有方案，用括號立即指出問題
- **減法話術**：「免 X、免 Y、免 Z」三連用
- **遞進三連擊**：三個遞進詞彙製造「越來越厲害」
- **場景掃射**：「地點 A｜地點 B｜地點 C」暗示到處都能用
- **包山包海感**：3 個以上具體物品列舉 + 「通通/一次/都能」收束

### 禁忌
- 大標不放技術名詞、產品型號、「本產品」「此款」、價格數字
- 不要像說明書、不要像論文、不要用廣告 cliché
- 「讓你 XX」一份文案不超過 5 次
- 比較表不直接寫出競品全名
