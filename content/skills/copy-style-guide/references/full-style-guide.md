# 募資頁面文案風格指南

> 框架管「什麼段落放在哪」，這份管「每一句話怎麼寫」。
> 從 15 份實戰範例的語句、節奏、修辭逐條拆解。


---

## 一、大標的寫法（橘色圖像化標題）

大標是整個段落的靈魂，消費者只看大標就要知道「這段在說什麼好處」。

### 1-1｜六種大標句型

**① 反問刺痛型** — 用問句戳中消費者的日常不滿

```
你今天也因為螢幕，委屈自己了嗎？（AIBOX）
你家到底有多少行李箱？（VELO）
討厭魚一直死心情很差？（悠合）
不夠涼叫什麼冷氣？（SANSUI）
生活中的臭味到底要多煩？（ECOHEAL）
你為了對抗臭味做了多少努力？（ECOHEAL）
有時候真的騰不出手打字...（WONDER）
想在戶外喝杯好咖啡有多困難？（OutIn）
```

規律：
- 用「到底」「也」「真的」加強共鳴語氣
- 問句結尾不一定要問號，「...」的留白有時更有力
- 問的是消費者**已經有的感受**，不是陌生的概念

**② 宣言否定型** — 否定現狀，建立新的標準

```
除味不能憑感覺，得要趕盡殺絕（ECOHEAL）
不是抑制，而是主動殲滅臭味因子！（ECOHEAL）
生活不該被螢幕綁架！可以更自由！（AIBOX）
能語音輸入，幹嘛用手打？（WONDER）
用他牌投影機，別再騙自己能在家看電影了（JMGO）
市面標榜的冰沙機，其實只是果汁機（DIKE）
最好的飲水體驗，就是直接喝！（POIEMA）
```

規律：
- 「不是 A，而是 B」的對比結構
- 「不能 / 不該 / 別再」打破消費者的將就心態
- 語氣偏強硬、篤定，有底氣

**③ 擁有想像型** — 讓人想像「用了之後的美好」

```
想怎麼看就怎麼看（AIBOX）
每次冒險，都值得一杯 Espresso（OutIn）
擁抱曠野，現萃入喉（OutIn）
讓你穿越進遊戲的眼鏡（Dream Glass）
喵臨天下！在家打造貓的天堂（Hug）
悠合共存，一方無憂純淨（悠合）
小小的帶出門、滿滿的裝回家（VELO）
四季淨好，無論冬夏（POIEMA）
```

規律：
- 不提產品功能，只提「用了之後的狀態」
- 短句、有節奏感、接近 slogan 語感
- 常用對仗：「小小/滿滿」「擁抱/現萃」

**④ 數字衝擊型** — 用一個極端數字讓人停下來

```
日本 Makuake 最受歡迎的掃地機，募資破億日圓（Neabot）
韓國售出超過 2 萬組，熱銷 8500 萬台幣（MONACOOK）
海外募資總額超過 2 億台幣（JMGO）
0.000001 秒延遲，比一般快 1 萬倍（Dream Glass）
世界最強 6 道過濾技術——能 6 個月不換水的黑科技（悠合）
一台取代 10 種家電（Greenis）
```

規律：
- 數字盡量用「最、破、超過」來放大
- 比較基準要明確（「比一般快 X 倍」「超越業界 X」）
- 數字 + 情緒詞搭配（「破億」「暴風」「最強」）

**⑤ 場景召喚型** — 直接喊出一個使用場景

```
串流時代來臨！Let's Moving！（AIBOX）
你也是 OUTDOOR 咖嗎？（SANSUI）
乾杯！成為朋友間的話題（DIKE）
在家的任何角落，守護你的歲月靜好（POIEMA）
沙漠、雪地、山巔、森林、海岸（OutIn）
```

規律：
- 召喚的是一個身份認同，不是一個產品需求
- 常搭配「你也是 XX 嗎？」的認同提問

**⑥ 加法公式型** — 用等號或加號創造意外組合

```
KNOT ＋ 一般毛巾 ＝ 毛巾殺菌機（ECOHEAL）
KNOT ＋ 衣櫥 ＝ 電子衣櫥（ECOHEAL）
水體穩定 ＋ 適當照明 ＋ 充足溶氧 ＝ 魚草應有的生態（悠合）
```

規律：
- 用日常物品 + 產品 = 意想不到的功能
- 讓消費者自己腦補「原來可以這樣用」


### 1-2｜大標的字數與節奏

| 類型 | 字數範圍 | 節奏 |
|------|----------|------|
| 破題主標 | 8-15 字 | 一口氣讀完，像一拳打過來 |
| 段落大標 | 10-20 字 | 可以有頓號或逗號製造呼吸點 |
| 場景大標 | 5-10 字 | 極短，像標籤貼在圖上 |

**黃金法則：大標裡永遠不出現技術名詞。** 技術放副標或內文。

```
✗ R290 環保製冷壓縮機（這是技術，消費者不會心動）
✓ 不夠涼叫什麼冷氣？（這是感受，消費者會點頭）
  └ 副標再接：R290 環保製冷壓縮機，製冷量高達 2000BTU
```

## 二、副標的寫法（藍色圖上文字）

副標的角色是**補充大標的具體畫面或數據**，讓大標的感性有一個理性落點。

### 2-1｜三種副標功能

**① 數據補充**
```
大標：業界最強暴風吸力
副標：超越業界 2500Pa，灰塵、毛髮、塵蟎通通帶走（Neabot 4000Pa）

大標：能 6 個月不換水的黑科技
副標：節省 24 倍的時間！（悠合）

大標：20Bar 專業高壓
副標：義式咖啡機的現萃實力（OutIn）
```

**② 場景畫面**
```
大標：想怎麼看就怎麼看
副標：串流影音｜無線娛樂（AIBOX）

大標：沒有空間限制，走到哪看到哪
副標：客廳看完電影，到臥房繼續看影集！（AIBOX）

大標：市售最小，一提就走
副標：夠方便，你才想帶出門！（SANSUI）
```

**③ 操作引導**
```
大標：用科技聰明下廚
副標：解放雙手，自動出好菜（Greenis）

大標：輕輕一轉，開始淨化
副標：自由調整想淨化的時間——30 分鐘｜60 分鐘｜120 分鐘（ECOHEAL）
```

### 2-2｜副標的語感規則

- **永遠比大標具體一階**：大標是感受，副標是「感受的來源」
- **可以出現數字**，但要翻譯成人話：「2000BTU」→「製冷量高達 2000BTU」不夠 →「創造 11°C 的天堂感受」才對
- **分隔符號用「｜」**而非「/」，視覺更乾淨
- **字數 10-25 字**，不超過兩行

## 三、內文的寫法（灰色小字）

內文是給「已經被大標副標吸引，想了解更多」的人看的。

### 3-1｜內文的口吻

**像朋友在跟你解釋，不像說明書在教你。**

```
✗ 本產品採用 PHIT 光合離子化技術，透過奈米光合觸媒產生淨化因子。
✓ 奈米光合觸媒在紫外光的照射下，能將空氣解離成具有殺菌能力的多種光合淨化因子。（ECOHEAL）

✗ 產品搭載 dToF 雷射偵測模組。
✓ 只需掃描一次，牢記家中平面圖，床底、沙發底都不放過，完整呈現在 App 上一目瞭然。（Neabot）

✗ 採用高碳鋼材質刀頭。
✓ 高碳鋼材質抗刮耐磨，4D 推動設計均勻翻動食材。（Greenis）
```

**規律：**
- 技術名詞出現後，**同一句話內就要接上「所以你會得到什麼」**
- 不用「本產品」「此款」這種距離感的詞
- 可以有驚嘆號，但一段最多一個

### 3-2｜內文的長度

- 每段內文控制在 **2-3 行，不超過 50 字**
- 如果需要解釋更多，用分段或條列，不要寫一大坨
- 範例裡的內文平均字數：30-45 字

## 四、痛點段的語感

痛點段是整份文案「情緒最濃」的地方，語感要從這裡和功能段做出區別。

### 4-1｜困擾列舉的寫法

**Greenis 風格——「困擾一、二、三、四」的結構化敘述：**
```
困擾一：烹飪器具和家電，把廚房堆得滿滿
（展開 1-2 句生活細節）

困擾二：雖然依照食譜，可是卻無法完整掌握火候和熟度
（展開 1-2 句）
```

特徵：像在幫消費者「代言」他的煩惱，語氣溫和、帶一點無奈

**AIBOX 風格——「好委屈」的情緒標籤：**
```
追劇但只能盯著手機？小螢幕傷眼，好委屈
想到客廳看電影，卻被家人搶先？休息還要搶，好委屈
```

特徵：每個痛點最後貼一個情緒詞「好委屈」，重複堆疊製造共鳴

**SANSUI 風格——「魔王關卡」的遊戲化命名：**
```
移動冷氣有 4 大魔王關卡
「超耗電」「不會冷」「搬不動」「沒效率」
```

特徵：把問題包裝成「要打的怪」，語氣輕鬆但問題很重

**ECOHEAL 風格——「你做了多少努力」的徒勞感：**
```
到處噴除臭劑（擔心化學成分飄在空氣中）
空氣清淨機（沒辦法完全去味）
放咖啡渣、橘子皮（消耗又不美觀）
還是只能委屈自己隨時間散去.....
```

特徵：每個方案後面用括號打臉，最後用「.....」製造無力感

### 4-2｜從痛點轉到產品的「橋接句」

痛點說完，不能直接跳到功能。需要一句「橋接」：

```
生活不該被螢幕綁架！可以更自由！（AIBOX）
SANSUI 極冷先鋒各個擊破，讓你再次享受山林的涼爽（SANSUI）
你的全能廚房幫手，成為料理神廚，一台就足夠（Greenis）
OutIn Nano 讓你深入自然，品味也絕不妥協（OutIn）
DIKE 用 100% 原汁做成冰品，不用冰塊、不用預冷，把飲品倒入就好（DIKE）
```

**規律：**
- 橋接句 = 「問題的否定」+「產品帶來的新世界」
- 語氣從「無奈」瞬間切換成「篤定」
- 常用「不該 / 可以 / 讓你」作為轉折詞

## 五、功能段的語感

功能段要在「讓人心動」和「讓人信服」之間切換。

### 5-1｜規格翻譯公式

**公式：規格數字 → 「所以你的生活會怎樣」**

```
4000Pa 吸力
→ 灰塵、毛髮、塵蟎通通帶走（Neabot）

5200mAh 電池
→ 一次清潔 55 坪（Neabot）

2.5W 功率
→ 24 小時運轉 1 個月電費只需 5 塊台幣（ECOHEAL）

7500mAh 大電量
→ 熱水萃取 200 杯 / 冷水萃取 5 杯（OutIn）

390W 低功率
→ 整晚使用也不怕營區跳電（SANSUI）

670g
→ 像一般寶特瓶的重量（OutIn）
```

### 5-2｜「通通 / 都能 / 一次」的包山包海感

範例裡大量使用「通通」「都能」「一次搞定」這類詞彙，製造「什麼都包了」的安心感：

```
灰塵、毛髮、塵蟎通通帶走（Neabot）
人體汗味、食物腐敗、寵物便溺通通不留（ECOHEAL）
掃除、拖地、自動集塵一次搞定（Neabot）
Youtube、Netflix、Disney+ 通通有！（AIBOX）
醬油膏、咖啡漬、粉塵、牛奶，乾掉也能一次清掃乾淨（Neabot）
可樂｜養樂多｜奶茶｜紅酒｜咖啡｜果汁（DIKE）
```

**技法：用 3 個以上的具體物品做列舉，最後接一個「通通/一次/都能」收束。**

### 5-3｜「不用 / 免 / 不必」的減法話術

消費者怕麻煩。功能段要不斷告訴他「你不用做什麼」：

```
不用換濾網、不用洗機器（ECOHEAL）
免安裝、免接管線、免打洞（POIEMA）
免預冷、免冷凍（DIKE）
免濾紙、免量杯、免秤重（OutIn）
不用複製貼上，直接出現在對話框（WONDER）
不用鑽洞釘牆、安裝簡單，搬家也能帶著走（Hug）
不用預先冷凍飲料、準備冰塊（DIKE）
不用手洗！一鍵自動清洗（DIKE）
不用接東接西，打開直接看！（JMGO）
不用手調焦距！不用拿雜物墊高！（JMGO）
```

**規律：「免 X、免 Y、免 Z」三連用效果最強。**

## 六、標點符號與視覺節奏

### 6-1｜標點符號的情緒功能

| 符號 | 用途 | 範例 |
|------|------|------|
| **！** | 興奮、篤定、打氣 | 「一台抵多台，聰明料理免動手！」 |
| **？** | 質疑現狀、引發共鳴 | 「你今天也因為螢幕，委屈自己了嗎？」 |
| **｜** | 場景 / 功能並列分隔 | 「串流影音｜無線娛樂」「寵物｜油煙味」 |
| **——** | 補充解釋 / 翻譯規格 | 「業界最強——4000Pa 暴風吸力」 |
| **......** | 無力感、留白 | 「還是只能委屈自己隨時間散去.....」 |
| **，** | 節奏換氣點 | 「小小的帶出門、滿滿的裝回家」 |
| **Ｘ** | 乘號，暗示組合加乘 | 「高品質電機 X 大扭力馬達」 |

### 6-2｜行距與呼吸感

- **大標和副標之間不放內文** → 讓視覺有留白
- **每個功能段之間空一行** → 手機閱讀時不會黏在一起
- **連續的痛點列舉，每條獨立成段** → 一個痛一個畫面
- **內文不超過 3 行就要換段或插圖**

### 6-3｜感嘆號使用頻率

- **大標：約 30% 的大標用感嘆號**（主要在場景召喚型和宣言否定型）
- **副標：約 50% 用感嘆號**（副標常常是「驚喜感」的載體）
- **內文：極少用**，最多一段一個
- **同一個畫面裡不要連續出現兩個感嘆號**

## 七、人稱與語氣

### 7-1｜人稱使用規則

| 人稱 | 使用時機 | 範例 |
|------|----------|------|
| **你** | 痛點段、場景段 — 直接對話 | 「你今天也委屈自己了嗎？」「讓你再次享受山林的涼爽」 |
| **我們** | 品牌故事段、承諾段 | 「POIEMA 比你更在意」「我們只要最純粹」 |
| **省略主語** | 功能段 — 讓產品自己說話 | 「一鍵清洗，清潔同樣不沾手」「30 分鐘速凍」 |
| **擬人化第三人稱** | 寵物類 — 站在寵物角度 | 「讓貓皇安全地跳上跳下」「君臨天下是貓皇的天性」 |

### 7-2｜語氣光譜

整份頁面的語氣不是固定的，會隨段落位置做漸變：

```
Opening → 溫暖自信（像老朋友推薦好東西）
Why 痛點 → 同理共鳴（像閨蜜在幫你抱怨）
橋接句 → 篤定有力（像教練說「夠了，交給我」）
功能展開 → 俐落專業（像產品經理在做簡報）
技術深入 → 可靠沈穩（像工程師在跟你保證）
Trust → 溫暖安心（像品牌在承諾「我在這裡」）
方案價格 → 直接乾脆（像店員說「就是這個價」）
```

## 八、對比表的文字風格

比較表不只是數據並列，**文字的選擇就是在暗示「你應該選我」**。

### 8-1｜自己的欄位

- 用正面動詞：「自動」「智慧」「強化」
- 數據加粗或加符號：✓、★
- 常在數據後面加一句人話：「2.5L 大容量——天天打掃每個月只要清一次」

### 8-2｜競品的欄位

- 客觀但暗示不足：「一般」「需要」「手動」
- 用 ✗ 或「無」標記缺失功能
- 不攻擊品牌名，用代稱：「韓國Ｎ牌」「飛XX」「他牌」

### 8-3｜表格下方的收束句

```
把一般 RO 的多濾芯過濾，濃縮在同一支濾芯裡，淨化能力提升，更直覺也更簡約！（POIEMA）
與「夾式」把手相比，結構更穩固，可承重超過 5 公斤（MONACOOK）
```

## 九、特殊修辭技法

### 9-1｜類比翻譯

把技術語言翻譯成日常經驗：

```
670g → 像一般寶特瓶的重量（OutIn）
0 分貝 → 跟我們比起來，其他清淨機就太聒噪了（ECOHEAL）
91% 透光率 → 水晶般剔透清晰（悠合）
一次 20 隻貓貓都沒問題！ →「100 公斤」的生活化翻譯（Hug）
一年只要 $1,990 → 相較於頻繁更換的他牌濾芯（POIEMA）
```

### 9-2｜遞進三連擊

三個遞進的詞彙，製造「越來越厲害」的感覺：

```
破壞｜分解｜沉降（ECOHEAL）
過濾 ➜ 儲水 ➜ 直飲（POIEMA）
掃除、拖地、自動集塵（Neabot）
切末、剁泥、碎丁（Greenis）
雪泥／奶昔／霜淇淋（DIKE）
```

### 9-3｜括號打臉法

在列舉消費者現有方案時，用括號立即指出問題：

```
到處噴除臭劑（擔心化學成分飄在空氣中）
空氣清淨機（沒辦法完全去味）
放咖啡渣、橘子皮（消耗又不美觀）

手沖咖啡（需要一堆裝備，準備麻煩又佔空間）
濾掛咖啡（也要花時間煮熱水）
即溶咖啡（味道單調無聊）
```

### 9-4｜重複節奏感

同一個句式重複 3 次以上，製造洗腦效果：

```
好委屈...好委屈...好委屈...（AIBOX）
免安裝、免接管線、免打洞（POIEMA）
不用冰塊、不用預冷（DIKE）
不用手調焦距！不用拿雜物墊高！（JMGO）
```

### 9-5｜從大到小的場景掃射

用「地點 A｜地點 B｜地點 C」快速列舉使用場景，暗示「到處都能用」：

## 十、禁忌與地雷

### 10-1｜永遠不要在大標裡出現的東西

- 純技術名詞（R290、dToF、PHIT）→ 放副標
- 產品型號（Q11、N1S Ultra）→ 放在開頭或規格表，不放功能段大標
- 「本產品」「此款」「該設備」→ 直接用產品名或省略主語
- 價格數字 → 只出現在方案段

### 10-2｜內文的語感地雷

- **不要像說明書**：「本產品採用 XX 技術，具備 XX 功能」
- **不要像論文**：「根據實驗數據顯示，其淨化效率達到 99.99%」→ 改成「不說大話，最完整除臭的實驗測試」
- **不要像廣告文案 cliché**：「顛覆性的創新」「無與倫比的體驗」「全球首創」
- **不要一直用「讓」開頭**：一份文案裡「讓你 XX」不超過 5 次

### 10-3｜比較表的禁忌

- 不直接寫出競品全名（用代稱 or 模糊化）
- 不用攻擊性語言（「他牌很爛」）→ 用數據讓消費者自己判斷
- 不只比自己贏的項目 → 要有全面性，才有公信力

## 十一、品類語感微調

同一套風格框架，在不同品類要做微妙的語感調整：

### 家電 / 清潔類
- Why 段要花最多力氣 → 因為消費者不覺得自己有問題
- 語氣偏「提醒」：「你知道嗎？」「你以為的乾淨其實不夠」
- 實驗數據和認證放多一點 → 這個品類的信任門檻高

### 廚房 / 料理類
- 功能段要配菜色照片 → 文字再好，不如一張蔥爆牛肉
- 語氣偏「輕鬆」：「我家也有熱炒店」「成為料理神廚」
- 「一台抵 X 台」是核心話術

### 寵物類
- 全程站在寵物視角 → 「貓皇」「喵臨天下」「讓貓皇監督你賺罐罐錢」
- 功能翻譯成「對寵物的好」而非「對主人的方便」
- 情感連結 > 理性說服

### 3C / 影音類
- 規格數字不能省，但要「翻譯」
- 語氣偏「熱血」：「征途刻不容緩」「大殺四方」「開拓無垠的遊戲視野」
- KOL 推薦權重高 → 3C 消費者很吃測評

### 小眾 / 興趣型
- 語氣偏「文青」：「人呼吸空氣、魚仰賴活水」
- 不用大眾化的痛點 → 改用圈內人才懂的共鳴
- 美感和質感用詞比例提高

### 出行 / 交通類
- 語氣偏「挑戰」：「你家到底有多少行李箱？」
- 「省空間」「省錢」是隱藏的購買動機，但明面上要講「自由」
- 暴力測試 / 耐用度是必殺信任段
