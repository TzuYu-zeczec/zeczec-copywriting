# 募資貼文撰寫規範

> 本文件為 FB／IG 貼文的撰寫通則，適用於「正式開賣貼文」及所有「倒數日程貼文」。
> 開賣貼文必須嚴格遵循完整六段結構；倒數日程貼文則以各自的核心任務為主，格式可參考但不強制完整。

---

## 一、基底通則

- **每行 20 個全形文字以內**（A 段除外），超出必須換行
- 為了版面好看，盡量每一行都控制在 20 個全形文字以內
- 各段之間用**空行**分隔，合併成一段完整貼文
- CTA 連結置於 B 段（開頭）＋ F 段（結尾），頭尾呼應
- 連結一律使用 `（連結）` 作為佔位符，實際發文時替換

---

## 二、貼文六段結構（ABCDEF）

### Ａ段｜標題列

- 配合廣告圖片，顯示在圖片下方
- 受眾**第一眼**看到的地方，必須放最重要的訊息
- **不受 20 字限制**（此段為唯一例外）
- 兩種做法：
  - ① 優惠倒數計時，製造急迫感
  - ② 口語化向受眾說話（例：「你還在用舊的 OO 嗎？」）
- 格式：

```
貼文標題：【 產品名 】主訴求標語
連結：短語.x.短語.x.短語
```

- 範例：

```
貼文標題：【 ✧ 小炫風手持風扇 ✧ 】
         親子出遊神器 🌞 倒數 3 天入手機會｜與小孩一起清爽出門不粘膩
連結：親子出遊.x.降溫神器.x.倒數三天

貼文標題：⚠️ 即將絕版 ⚠️
         《 FlipGO Pro 折疊便攜螢幕 》大禮包優惠最後１天
連結：最高現省2.4萬.x.送無線手寫板

貼文標題：除臭革新技術登場 ☼ 𝐊𝐍𝐎𝐓 光子除味器 ☼
連結：主動殲滅臭味.x.早鳥優惠

貼文標題：過年終於要去日本玩 🇯🇵✈️
         但英文不好日文更是......這樣自由行真的可以嗎？ 😭
連結：翻譯神器.x.說中文就好
```

### Ｂ段｜開場標語

- 貼文的**正上方**，受眾第二眼看到的地方
- A 段標題的換句話說 ＋ 本篇主力訴求標語
- **放上第一次 CTA 連結**
- 範例：

```
最後５天 ⏰ PHILIPS 小炫風・手持風扇 🌪️
募資優惠組合最後倒數 ➤ （連結）

募資突破 150 萬，大禮包優惠最後一天 💰
➙ （連結）

【 募資正式開跑 】迎接清爽夏日 ☀️
別讓流汗粘膩破壞出遊的心情
➜ （連結）
```

### Ｃ段｜產品名＋主力宣傳重點

- 放產品名，搭配本篇要主打的重點特色
- 兩種方式：
  - ① **痛點型**：提出痛點 → 產品完美解決 → 取代舊方案。互動性強的語氣，給予**理性利益**
  - ② **情境型**：塑造完美使用情境，重視氛圍感，給予**感性利益**
- 範例（痛點型）：

```
夏日旅行最怕 #熱到影響興致 😠
受夠一出門就全身黏膩...

❌ 逛街逛到脫妝
❌ 遊樂園排到小孩熱哭
❌ 親近戶外被太陽蒸發

🌀小炫風・手持風扇 - 口袋降溫神器 🌀
親子同樂 ▪ 涼爽持妝 ▪ 出國旅遊 ▪ 登山露營
```

- 範例（情境型）：

```
   ✧ ˚ ₊  輕盈小巧，渦輪散熱  ₊ ˚ ✧
  ⍋⍋  PHILIPS 小炫風 · 手持風扇  ⍋⍋

### Ｄ段｜條列式產品特色

- 列出 **4～5 個**產品特色
- 每個特色的格式：**符號 + 特色名（≤ 10 字）**，後面補一句**詳細敘述（15～25 字）**
- 特色前需有文字符號做出顯眼標示
- 範例：

```
▌最強風速 5.2 m/s｜帶走皮膚熱氣 🌀
▌100 段風速可調  ｜客製舒適涼風 🌪️

▌輕便收納不占空間｜機上也能輕鬆帶 🧳
```

- 範例（另一種排列方式）：

```
⓵ 分解異味｜主動撞擊，破壞異味的化學鏈
⓶ 除霉滅菌｜破壞病毒外殼、細菌細胞膜
⓷ 解決空汙｜電荷吸附 PM2.5，沉降為灰塵
```

- 範例（展開敘述型）：

```
🚩 一秒連接，隨時進入狀態
     ⊚ Type-C 直連，不需要其他線
     ⊚ 不需要每次連接都開軟體

### Ｅ段｜優惠活動＋促購字眼

- 常用字眼：**免運、現省、幾折、最後優惠、原價、刷卡分期、限量、倒數**

## 三、溝通符號通則

**大前提：同一篇貼文符號不能太多。段落標題符號只能用一種、列點符號只能用一種。**

### 第一類｜段落標題

```
符號：▌ ▐ 【】 ◤◢ 𒈝
用途：凸顯產品名，或做分段特色的開場
範例：
  𒈝 RayNeo Air 3 口袋電視 👓 𒈝
  ◤      冷房速度超越一般循環扇
               打造室內最佳訓練環境      ◢
  【 多項功能 & 強悍硬體 🖥 】
  ▌維持體態健康的層層關卡▐
```

### 第二類｜文字分隔

```
符號：｜
用途：同一句中分開「特色」與「敘述」
範例：雙系統適配｜手機、筆電、家機都能播
```

### 第三類｜列點式

```
符號：𒁈 ⊚ ■ ◆ ⬣ ✦ ✧ ▌
用途：條列特點
範例：
  ▌與生活完美結合
  ✦ ８極點精準量測
```

### 第四類｜箭頭

```
符號：➙ ➜ ➡ ➤
用途：連結前導引，或表示過程
範例：
  這裡看優惠 ➤
  看更多細節 ➜
  前往募資 ➙
  先抽 ➡ 再洗 ➡ 後轟
```

### 第五類｜情境段落

```
符號：◠◡◠  ✧ ˚ ₊  ⍋
用途：段落標題的變體，配合內容設計類似區塊的情境
範例：
   ✧ ˚ ₊  輕盈小巧，渦輪散熱  ₊ ˚ ✧
  ⍋⍋  PHILIPS 小炫風 · 手持風扇  ⍋⍋
```

### 彈性組合

以上符號可彈性搭配，例如：

```
▌ ✦  雙系統 1000 多種裝置適配 🛠  ✦ ▐
```

## 四、貼文類型比較

|  | 預熱問卷貼文 | 開賣貼文 | 倒數日程貼文 |
|--|------------|---------|------------|
| **豐富度** | 開賣貼文的精簡版 | 最完整、最豐富 | 著重核心任務，相對精簡 |
| **結構** | 遵循 ABCDEF 六段，但篇幅較短 | 嚴格遵循 ABCDEF 六段 | 可參考 ABCDEF，不強制完整 |
| **Ｃ段展開** | 只保留一個主力情境（痛點型或情境型擇一） | 完整展開產品賣點（痛點／情境＋技術解析） | 圍繞該波核心任務（QA／方案／折扣碼＋搶購秘訣） |
| **Ｄ段特色** | 精簡為 3～4 個關鍵特色 | 4～5 個完整條列 | 可精簡或省略 |
| **Ｅ段優惠** | 不放優惠方案，改為問卷引導語 | 完整方案＋促購字眼 | 可精簡帶過 |
| **Ｆ段 CTA** | 導向問卷連結 | 導向募資頁連結 | 導向貼文／問卷／募資頁 |
| **整體目的** | 讓受眾認識產品並填問卷 | 全力轉換下單 | 消除疑慮／製造期待／鋪墊行動 |

> **重點**：預熱問卷貼文是開賣貼文的「精簡版」，目的不同——收集名單而非轉換下單，結尾固定用「募資即將開賣，這邊看更多細節」導向問卷。倒數日程的核心任務不同——「倒數七天 QA 消除疑慮」「倒數三五天 製造期待」「倒數一天 鋪墊行動」——內容編排應以核心任務為主，格式亦可參考 ABCDEF 結構。

### 各波貼文的核心任務提醒

| 波次 | 核心任務 | 貼文重心 |
|------|---------|---------|
| 預熱問卷 | 收集名單 | 一個主力情境＋關鍵特色，導向問卷 |
| 倒數 7 天 | 消除疑慮 | QA 問答為主體，解答常見問題 |
| 倒數 3～5 天 | 製造期待 | 方案價格 / 開箱實證為主體 |
| 倒數 1 天 | 鋪墊行動 | 搶購秘訣＋提前註冊帳號為主體 |
| **正式開賣** | **全力轉換** | **完整 ABCDEF 六段，資訊量最大** |

## 五、主力貼文輸出規則

**主力貼文（預熱問卷主力貼文、正式開賣主力貼文）在產出時，直接輸出完整貼文，不標註段落標籤。**

- 不寫「A段」「B段」「Ａ段｜標題列」等任何段落標記
- 段落之間以空行自然銜接
- 呈現使用者可直接複製發文的最終成品
- ABCDEF 結構是撰寫時的內部邏輯參考，不是輸出格式

> 此規則僅適用於「主力貼文」（問卷主力、開賣主力）。倒數日程貼文因內容較短、結構較彈性，是否標註段落標籤皆可。
