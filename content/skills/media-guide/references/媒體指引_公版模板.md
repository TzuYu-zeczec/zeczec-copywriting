# 媒體指引｜公版模板

> **字體規格**
> - 標題：置中 18 級粗體
> - 副標題：置中 14 級粗體
> - 敘述文字：12 級
>
> 🗂 標有 `【必填】` 的每份都要填，`【選填】` 視情況決定，說明文字（灰字）在正式輸出前刪除。

---

## 第一段

**標題（18 級粗體置中）：**
```
產品名稱
```

**副標題（14 級粗體置中）：**
```
主力 Slogan
```

**[ 配圖 ]**

**敘述文字（12 級）：** 【必填，約 100–200 字】
```
以「市場現有方式的不足」為起點，帶出這個產品為什麼不一樣。
結構：現有痛點 → 這個產品怎麼解決 → 使用者得到的改變。

若有多個品相（款式），在這段後面依序展開各品相介紹。
每個品相：名稱 + 1–2 句核心差異 + 適合誰用。
```

---

## 第二段

**標題（18 級粗體置中）：**
```
【 〔網紅帳號名〕｜媒體指引內容 】
```

**敘述文字（12 級）：** 【必填】
```
希望〔網紅帳號名〕以「帳號風格」自由發想，替〔產品名〕企劃圖文曝光主題！
傳遞出〔主要切角〕的必要感，並將這支商品〔預計拍攝場景〕的使用情境展示出來，
讓網友了解〔產品 Slogan〕！

填寫說明：
- 〔網紅帳號名〕：對方的帳號名稱（直接稱呼）
- 〔產品名〕：本次合作的具體產品或組合
- 〔主要切角〕：這個產品最想讓人感受到的核心主張（2–4 個字的名詞，例：「主動除臭」「親子安全」）
- 〔預計拍攝場景〕：具體地點或情境（例：廚房、車內、旅途中）
- 〔產品 Slogan〕：大標或核心一句話
```

---

**副標題（14 級粗體置中）：**
```
📌 拍攝指引
```

**■ 希望拍攝的切角** 【必填】
```
以什麼身份切入 → 遇到什麼狀況/痛點 → 如何用這個產品解決

例：
以「料理愛好者」身份，遇到廚房油煙一直殘留的困擾，
開窗、電風扇都沒用，發現用 Elev. 讓油煙直接消失。
```

**■ 必備拍攝畫面** 【必填】
```
這些畫面一定要有：
- Before & After（before 要讓人一眼看出「問題真實存在」）
- 產品外觀特寫（正面、開機狀態、細節）
- 品牌認證 / 技術背書畫面
- 活動優惠資訊帶出
```

**■ 建議拍攝畫面** 【選填】
```
這些畫面加分：
- 使用者情境（產品在生活中自然出現的樣子）
- 多款產品或多場域搭配使用
- 開箱、包裝展示（如大貨包裝已確定）
```
