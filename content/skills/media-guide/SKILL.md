# 媒體指引產生工具

## 你的任務

根據使用者提供的產品資訊，依照四段公版結構產出一份完整的媒體指引（.docx）。

---

## 字體規格（嚴格遵守）

| 元素 | 對齊 | 大小 | 樣式 |
|------|------|------|------|
| 標題（段落大標） | **置中** | **18pt**（36 halfpoints） | **粗體** |
| 副標題 | **置中** | **14pt**（28 halfpoints） | **粗體** |
| 敘述文字 | 左對齊 | 12pt（24 halfpoints） | 一般 |
| 特色標題（第三段內） | 左對齊 | 12pt | **粗體** |

字型統一使用 **Arial**。

---

## 第一步：確認輸入資訊

**必要資訊**（沒有就問）
- 產品名稱與品牌
- 主力 Slogan（若無，由你根據產品判斷）
- 產品核心功能（3–8 項）
- 目標受眾 / 使用情境

**選填資訊**（有就填，沒有就跳過或留空白）
- 網紅帳號名稱與風格描述
- 希望的拍攝場景
- 注意事項（品牌名念法、禁止詞彙、樣品包裝差異等）
- 補充連結（問卷、募資頁、素材包）
- 售價資訊、活動檔期
- 合作時程、過稿規範

若產品資訊以文件或連結形式提供，先讀取再進行。

---

## 第二步：撰寫四段內容

---

### 📌 第一段｜產品介紹

**標題（18pt 粗體置中）：** 產品名稱

**副標題（14pt 粗體置中）：** 主力 Slogan

**「配圖」佔位**（在 docx 中呈現為灰底方框）

**敘述文字（12pt）：** 約 100–200 字

寫法結構：
1. 市面現有做法的不足（點出痛點）
2. 這個產品如何不同（核心技術或差異點）
3. 使用者得到的改變

若有多個品相（款式），在這段後面依序展開：
- 每個品相：名稱 + 1–2 句核心差異 + 適合誰用

語氣：自然口語，像「懂市場的人跟你說話」，不用學術腔。
禁止：「業界頂尖」「革命性」「顛覆」等空話。

---

### 📌 第二段｜媒體指引內容

**標題（18pt 粗體置中）：** `【 〔網紅帳號名〕｜媒體指引內容 】`

若無指定網紅，標題改為：`【 媒體指引內容 】`

**敘述文字（12pt）：**

固定句型：
> 希望〔網紅帳號名〕以「帳號風格」自由發想，替〔產品名〕企劃圖文曝光主題！傳遞出〔主要切角〕的必要感，並將這支商品〔預計拍攝場景〕的使用情境展示出來，讓網友了解〔產品 Slogan〕！

填寫規則：
- **〔主要切角〕**：2–6 字的核心主張（從產品功能或使用情境提煉，要讓人「感受到必要性」）
- **〔預計拍攝場景〕**：具體地點或情境（例：廚房使用電動刷清潔縫隙、進門解鎖後連動全屋智慧家電）
- **〔產品 Slogan〕**：第一段的副標題或另外精煉的一句話

---

**副標題（14pt 粗體置中）：** `📌 拍攝指引`

三個 ■ 區塊，依序：

**■ 希望拍攝的切角**
以「身份」→「遇到什麼問題」→「如何解決」的邏輯推進。
說到讓網紅一讀就知道怎麼切入，有畫面感。

**■ 必備拍攝畫面**
這些畫面一定要有，清單式列出（條列，每條具體到「動作＋畫面效果」）：
- Before & After（before 畫面要讓觀眾感受到「這個問題我家也有」）
- 產品外觀、開機狀態、細節特寫
- 認證 / 技術背書畫面（若有）
- 活動優惠資訊帶出

**■ 建議拍攝畫面**
加分畫面，選填，列出 2–4 條。

---

### 📌 第三段｜重點特色

**標題（18pt 粗體置中）：** `【 〔產品名〕｜重點特色 】`

若有多款產品，每款各自有一個第三段區塊。

每個特色格式：
```
特色名稱｜一句核心主張（12pt 粗體，左對齊）

補充說明 A（12pt，左對齊）
補充說明 B（選填）

[ 配圖 ]（灰底佔位框）
```

規則：
- 特色名稱 = 網紅口播素材，要口語、直接，≤20 字
- 補充說明 = 字幕或旁白補充，可帶規格數字
- 特色順序：最有差異化的放最前面
- 數量：5–8 個為佳，不硬湊

禁止：
- 把規格堆進特色標題（「2.5Nm 大扭力高轉速」→ 改成「刷得乾淨不費力」）
- 每條都用同樣句型

---

### 📌 第四段｜補充資訊

**標題（18pt 粗體置中）：** `【 補充資訊 】`

**敘述文字（12pt）：** 依有無資訊填入，沒有的項目整段省略。

包含但不限於：
- **主力推廣組合**：組合內容、品項說明
- **售價資訊**：原售價 / 活動售價 / 活動檔期 / 折扣說明
- **品牌規範 / 用詞規範**：名稱念法、必帶品牌全名、禁止詞彙
- **參考資料**：官網、問卷、募資頁、素材包、參考形式影片
- **合作時程 / 過稿規範**：素材交件日、品牌審閱期、預計上線日、過稿方式

---

## 第三步：docx 輸出規範

讀取 docx skill 後，按以下規範輸出：

### 結構
- 封面頁：品牌名 ＋ 文件標題 ＋ 小字說明「語句可依媒體風格調整，意思不變即可」
- 四個段落間各加 PageBreak
- 空行使用 ZWSP（零寬空格）Paragraph，不用純空白行

### 「配圖」佔位框
使用單格 Table 呈現灰底方框（fill: `F5F5F5`），內文置中灰字 `[ 配圖 ]`，框線顏色 `DDDDDD`，上下 padding 約 400–600 DXA。

### 顏色
- 段落標題（18pt）：深灰 `333333` 或黑色（不用彩色，保持乾淨專業）
- 副標題（14pt）：深灰 `555555`
- 敘述文字（12pt）：深灰 `555555`
- ■ 區塊小標：深灰 `333333` 粗體

### 檔名格式
- 有網紅：`〔品牌名〕×〔網紅帳號名〕_媒體指引.docx`
- 無網紅：`〔品牌名〕_媒體內容指引.docx`
- 活動版：`〔品牌名〕_〔活動名〕_媒體指引.docx`

## 風格速查

### 主力 Slogan 語感
| 避免 | 改成 |
|------|------|
| 革命性的清潔體驗 | 能用電動的，幹嘛用蠻力刷？ |
| 最頂級的智慧鎖 | 台灣第一把通過 Matter 認證的智慧鎖 |
| 多功能除臭產品 | 不是抑制，是殲滅 |

### 特色標題語感
| 避免 | 改成 |
|------|------|
| 高效能馬達帶來強勁清潔力 | 高效馬達轉速，刷得乾淨不費力 |
| 具備 IPX7 防水等級 | 全機防水，用完直接沖 |
| 多種解鎖方式滿足各種需求 | 七種開門方式，照顧全家人的習慣 |

### 拍攝指引語感
| 避免 | 改成 |
|------|------|
| 展示產品外觀 | 桌面平拍產品正面，近拍開機鍵、出風口細節 |
| 展示清潔效果 | 磁磚黑垢特寫（before）→ 刷過後乾淨如新（after） |
| 生活情境 | 出電梯後說「嘿 Siri，幫我開門」，家門自動解鎖 |

## 收尾

完成 .docx 後：
1. `validate.py` 驗證格式
2. 儲存至使用者工作資料夾
3. `present_files` 呈現給使用者
4. 若有 `save-to-desktop` skill，執行存桌面
