# 募資專案開賣倒數架構

> 歸納自 7 個實戰募資專案（PHILIPS 小炫風、DIKE 好冰友雪泥機、FlipGO Pro 雙螢幕、Dripo REA1 浸漬咖啡機、neakasa magic 1 蒸氣衣櫥、OutIn Nano 隨時萃、RayNeo Air4 Pro 頭戴電視），適用平台：**嘖嘖**。
>
> ⚠️ **平台限定：本文案系統僅適用於嘖嘖平台，不涉及其他任何募資平台。**

---

## 一、整體節奏：預熱＋四波推進

| 波次 | 時間點 | 核心任務 | 一句話定位 |
|------|--------|---------|-----------|
| 預熱波 | 問卷推廣期 | 收集名單 | **認識**——讓受眾覺得「這東西好像不錯，填問卷看看」 |
| 第一波 | 開賣倒數 7 天（或 5 天） | 消除疑慮 | **安心**——讓受眾覺得「這產品我搞懂了」 |
| 第二波 | 開賣倒數 3～5 天 | 製造期待 | **心動**——讓受眾覺得「這價格／這開箱我想要」 |
| 第三波 | 開賣倒數 1 天 | 鋪墊行動 | **準備**——讓受眾「折扣碼拿到了、帳號註冊好了」 |
| 第四波 | 正式開賣當天 | 直接轉換 | **行動**——讓受眾「現在就去下單」 |

**統一發送時間：中午 12:00**（所有範例皆為此時段）

## 二、渠道配置總覽

每個時間節點同步發送以下渠道：

| 渠道 | 角色定位 | 受眾來源 |
|------|---------|---------|
| **FB／IG 貼文** | 公開觸及＋社群互動 | 粉專追蹤者＋廣告投放 |
| **EDM（電子郵件）** | 深度溝通＋專屬感 | 問卷填寫者名單 |
| **LINE 推播** | 即時觸達＋快速行動 | LINE 官方帳號好友 |
| **Messenger 推播** | 即時觸達＋快速行動 | FB Messenger 訂閱者 |
| **Chatbot 劇本** | 問卷回填追蹤＋開賣推播 | 完成問卷的 Messenger 用戶 |
| **SMS 簡訊**（選配） | 最後一哩觸達 | 有留電話的名單 |

## 三、各渠道格式規範

### 3-1. EDM（電子郵件）

- 圖片大小：**2MB 以內，寬度不超過 1080px**
- 內容量最完整：含主圖、方案表格圖、按鈕、分隔線
- 每封信結尾固定元素：
  - 「下封信件預告：{預告內容}」
  - 「加入主要收件匣」提醒
  - 「前往粉絲團私訊小編」聯繫入口
- 發送對象：問卷名單

### 3-2. LINE 推播

LINE 推播分為兩種後台，格式規範不同：

#### A. 機器人後台推播（Chatbot 後台）

- **14 個全形文字後斷行**
- 文字內**不放連結**（文字連結不能點擊）
- 文字下方**必須有按鈕**
- 按鈕負責承載所有導流連結

#### B. LINE OA 後台推播（官方帳號後台）

- **12 個全形文字後斷行**
- 文字內**可放連結**（連結可點擊）
- 文字下方**無按鈕**

#### LINE 推播變體：廣發折扣碼

有廣發折扣碼的專案，可多推一則純文字訊息。此時單次推播的訊息結構為：

```
訊息 1：文字（主要內容）
訊息 2：圖文訊息（主視覺＋連結）
訊息 3：純文字折扣碼
──────
一次吃掉 3 則訊息
```

### 3-3. Messenger 機器人推播

- **12 個全形文字後斷行**
- 文字內**可放連結**（連結可點擊）
- 文字下方**可放按鈕**（1～3 個）

### 3-4. Chatbot 劇本（Messenger）

Chatbot 劇本用於兩個節點：

#### A. 預熱問卷跳轉劇本（問卷填寫後觸發）

```
Step 1：
哈囉～{{user_name}}！
感謝您完成《 專案名稱 》前測調查問卷🙏
只要點擊下方「完成問卷」4個字，就能參加隱藏抽獎活動唷！

＊按鈕：完成問卷 → 跳 Step 2

Step 2：
啟動成功！完成以下步驟就有機會獲得
抽獎禮品：【待確認】

1. 在以下貼文中，標記 2 位朋友
2. 公開分享這則貼文
3. 請勿提及任何關於抽獎的訊息，否則將會被取消資格唷

貼文連結：【待補連結】

❇️ 本活動將於募資活動開跑時，公布獲獎名單（共會抽出 1 個）

＊按鈕：前往貼文
```

#### B. 上線推播劇本（開賣當天觸發）

```
{{user_name}}，就是今天！

中午 MM/DD（星期）12:00 募資活動準時開跑！

迅速前往《 專案名稱 》活動頁面
▶︎ {募資頁連結}

※ 折扣碼已經寄至您的信箱，趕快領取使用！
```

### 3-5. SMS 簡訊

- **總字數限制：70 個字元**（空格、英文字母、符號、標點、中文、網址全部計入）
- 網址長度也要算進 70 字元內（建議使用短網址服務）
- 一句話＋短連結，不做多餘修飾

```
範例（67 字元）：
正式開賣！RayNeo Air4 Pro 頭戴電視｜5折現省萬元：https://re.flyv.tw/d8EBG
```

### 3-6. FB／IG 貼文

> **完整規範請見獨立文件：「募資貼文撰寫規範.md」**
>
> 以下僅為快速摘要：

- **每行 20 個全形文字以內**（A 段除外），超出必須換行
- 貼文採 **ABCDEF 六段結構**：A 標題列 → B 開場標語＋CTA → C 產品名＋主力宣傳 → D 條列式特色 → E 優惠活動 → F 結尾＋CTA
- **開賣貼文**：嚴格遵循完整六段，資訊量最大，全力轉換
- **倒數日程貼文**：以核心任務為主（QA／方案／搶購秘訣），格式可參考六段但不強制完整
- 溝通符號五類（段落標題、文字分隔、列點式、箭頭、情境段落），同一篇**段落標題只能一種、列點符號只能一種**
- **主力貼文（問卷主力、開賣主力）產出時，直接輸出完整貼文，不標註段落標籤（不寫「A段」「B段」等標記）**——段落之間以空行自然銜接，呈現使用者可直接複製發文的最終成品

## 四、各波詳細架構

---

### 【預熱波】預熱問卷貼文——收集名單

**核心目標：用一篇精簡但完整的貼文介紹產品，引導受眾填寫前測問卷**

預熱問卷貼文的形式與正式開賣貼文相同（ABCDEF 六段結構），但篇幅較短：

- **Ｃ段**只保留**一個主力情境**（痛點型或情境型擇一），不需完整展開所有賣點
- **Ｄ段**精簡為**3～4 個關鍵特色**（不需 4～5 個完整條列）
- **Ｅ段**不放優惠方案（此時方案尚未公開），改為問卷引導語：「募資即將開賣，這邊看更多細節」
- **Ｆ段**結尾 CTA 導向問卷連結，而非募資頁連結

> **與正式開賣貼文的差異**：預熱問卷貼文是開賣貼文的「精簡版」，目的是讓受眾認識產品並填問卷，不是直接轉換下單。因此資訊量較少、不公布價格，收尾導向問卷。

### 【第一波】倒數 7 天——QA 懶人包

**核心目標：消除購買疑慮，讓受眾從「有興趣」變成「放心等開賣」**

#### EDM（公版 01）

```
信件標題：《 產品名 》10 大常見問答
副標題：募資即將開始，超值早鳥優惠搶先卡位
發送對象：問卷名單

結構：
1.【主圖】（2MB 內、寬度 ≤ 1080px）
2. 開場問候＋開賣時間預告
   感謝你關注《ＯＯＯＯ》並抽空填寫問卷，讓您久等了！
   我們即將在 202X 年 XX 月 XX 日（X）中午 12:00
   正式於嘖嘖募資平台上線！
   ✦ 開賣時間：MM/DD（星期）中午 12:00
   ✦ 開賣平台：嘖嘖
   ✦ 限時 72 小時，限量超值組合
3. QA 引言——從問卷收到許多回饋與疑問，整理 X 個常見問題
4.【QA 連結按鈕】常見 QA 解密（連結到貼文或獨立頁面）
5. QA 本體——
   Q：問題一？
   A：回答（2～3 行）
   （重複 7～12 題）
6. 加入重要收件匣提醒
7. 結尾——感謝＋粉專私訊入口
   「下封信件預告」不一定放（視情況）
```

#### 貼文

```
結構：
1. 開場——「募資準備開跑！搶先卡位」＋問卷連結
2. 引言——點出產品最大賣點，帶出「你是不是還有疑問？」
3. QA 本體——7～12 題常見問答
   ・格式：emoji 圖標 + 問題❓ → 回答（2～3 行）
   ・問題來源：前測問卷收集
   ・問題類型：功能疑問、使用方式、規格細節、保固售後
4. 收尾——「還有問題歡迎留言／私訊」
5. CTA——再次放問卷連結
```

#### LINE 推播

```
【機器人後台】14 全形字斷行，不放連結，底部按鈕導流
【LINE OA】12 全形字斷行，可放連結，無按鈕

結構：
1. 主標——「{產品名}｜即將開賣 🚀」
2. 一句話產品賣點
3. 問題條列——只列問題不放答案（5～8 題）
4. 導流語——「你想問的我們都幫你整理好了！」
5.（機器人版）按鈕：「QA 懶人包｜點我前往」→ 貼文連結
  （OA 版）文中直接放貼文連結
```

#### Messenger 推播

```
12 全形字斷行，可放連結，可放按鈕

結構：
1. 主標——「{產品名}｜即將開賣 🚀」
2. 一句話勾起好奇
3. 問題條列——只列問題不放答案（5～8 題）
4. 導流語——「快點擊下方按鈕看解答吧 ▼▼▼」
5. 按鈕：「QA 懶人包｜點我前往」→ 貼文連結

### 【第二波】倒數 3～5 天——方案公開／搶先開箱

**核心目標：公布價格與方案，用「划算感」和「實證」推動心動**

> 此波內容依產品屬性，有兩種主要變體：
> - **變體 A：方案＋價格公開**（適用多數專案）
> - **變體 B：搶先開箱＋KOL 評測**（適用需要實證的專案）
> - 部分專案會兩者並用（如 Dripo：開箱＋方案同時公布）

```

副標題：{方案亮點一句話}
發送對象：問卷名單

結構：
1.【主圖】
2.（若有 KOL 開箱）
   開箱引言——「特別邀請 ＯＯ達人【名稱】詳細使用」
   達人名稱＋頭銜（大標呈現）
   ■ 節錄推薦重點（2～4 個 bullet）
   「節錄影片或文章推薦的一句話」
   👉 看完整影片（按鈕連結）
   ───分隔線───
3. 方案區塊
   大標：保證最低價，錯過不再
   大標：募資方案公開！
   【方案圖片】
   方案 1——超值早鳥優惠現省 $OOO ＃限量送再省 $OO
   方案 2——...
   方案 3——...
   輸入折扣碼 OOO 再折 $OO（若已有折扣碼）
4. 結尾——感謝＋粉專私訊入口

```

   ✦ MM/DD（星期）中午 12:00 開賣
   ✦ 限時 72 小時，限量超值組合

   ▌主推組合（1＋1 組合／配件組合）
   ✦ 方案名稱 + 價格
   >> 現省 $XXX 元！

4. 技術／功能深度解析

```

```

1. 主標——「開賣倒數 X 天」

1. 主標——「開賣倒數 X 天」

### 【第四波】正式開賣——購買連結＋全力轉換

**核心目標：把所有蓄積的流量導向募資頁面，現在就下單**

#### EDM（公版 04）

```
信件標題：正式開賣 🔥【 產品名 】小標語
副標題：內含 ＯＯＯ 專屬折扣，倒數 XX 小時
發送對象：問卷名單

結構：
1.【主圖】

## 五、跨波串接機制

### 1. 問卷漏斗

```
FB 廣告／貼文／MSG
      ↓
   填寫問卷（收集 email + 手機）
      ↓
   Chatbot 預熱劇本觸發（隱藏抽獎＋社群分享）
      ↓
   進入 EDM 名單
      ↓
   倒數 7 天起收到系列信件
      ↓
   倒數 1 天收到折扣碼
      ↓
   開賣日收到購買連結
      ↓
   Chatbot 上線推播觸發
```

### 2. EDM 預告鉤子

每封 EDM 結尾放「下封信件預告」，維持開信動機：

| 波次 | 預告內容 |
|------|---------|
| 倒數 7 天 | 下封預告：方案價格公開／搶先開箱 |
| 倒數 3～5 天 | 下封預告：專屬優惠折扣碼 |
| 倒數 1 天 | 下封預告：募資購買連結 |
| 正式開賣 | 下封預告：評測開箱／使用心得 |

### 3. 折扣碼分發策略

- **折扣碼只在 EDM 中正式發放**（倒數 1 天＋開賣日重複提醒）
- 其他渠道（貼文、MSG、LINE）只提示「折扣碼已寄到信箱」或「填問卷領折扣碼」
- 目的：驅動受眾回到 EDM 渠道，確保高價值受眾被完整追蹤
- **例外：LINE 廣發折扣碼變體**——直接用第 3 則純文字訊息發送折扣碼

### 4. 平台帳號註冊引導

統一在倒數 1 天放入「搶購秘訣」教學：

```
● 請前往嘖嘖網址
● 點選右上角的頭像圖示
● 輸入註冊資訊後即可完成（可用 FB / Google 註冊）

「在明天開賣的瞬間搶先別人，省去註冊麻煩 🥰」
```

### 5. 信件收件匣提醒

每封 EDM 都要提醒（或至少前兩封）：

```
✨ 為了能更即時收到通知信，以下提供一個小撇步：
✨ 立即將這封信件移動至「主要收件匣」，就不會錯過上線通知！
```

## 七、注意事項

1. **發送對象一律為「問卷名單」**——整條漏斗的前提是前測問卷已收集完成
2. **所有渠道統一在中午 12:00 發送**——配合募資平台開賣時間
3. **EDM 是核心渠道**——內容最完整、折扣碼獨家發放、有預告鉤子串接
4. **LINE／MSG 是導流渠道**——不放完整答案，用「點我看更多」導向貼文或問卷
5. **LINE 推播注意後台差異**——機器人後台（14 字斷行、不放連結、必放按鈕）vs OA 後台（12 字斷行、可放連結、無按鈕）
6. **Messenger 推播**——12 字斷行、可放連結、可放按鈕
7. **SMS 嚴守 70 字元**——含網址長度，建議使用短網址
8. **倒數天數可依專案微調**——7-5-1、7-4-1、7-3-1、5-1 皆有實例，核心是三波內容不變
9. **「限時 72 小時」是常見的早鳥壓力機制**——多數專案在開賣後 72 小時內設定超早鳥截止
10. **EDM 圖片規範**——2MB 以內，寬度不超過 1080px
11. **平台限定為嘖嘖**——本系統所有文案、連結、註冊引導、短網址格式皆以嘖嘖為準，不適用於其他任何平台
