## 1. 整體架構

### 時間軸設計

結案倒數以「結案日」為錨點，反推 7 天啟動。核心節奏是「隔天加壓」：

```
結案日 -7  →  -5  →  -3  →  -1  →  -12H/-6H
（一）     （三）   （五）   （日）    （結案日當天）
```

實務上日期會落在不同星期，但間隔邏輯不變：7→5→3→1→當天。

### 渠道配置原則

- **貼文（FB）**：每個節點都發，是內容母版
- **EDM**：每個節點都發，是轉化主力
- **LINE**：倒數 7、3、1 天 + 最後 6H，中頻推播
- **MSG（Messenger）**：視專案需求，通常 7、3、1 天
- **SMS**：僅在最後 12H 或 6H 出動，終極收割

### 發布時間

- 標準時間：**12:00 中午**（全渠道統一）
- 最後 6 小時：通常 **18:00**
- SMS：可以 12:00 或 20:00

## 2. 五個時間節點的內容策略

### 節點一：倒數 7 天——「提醒你我還在，而且很值得」

**核心任務**：啟動倒數意識，重申產品價值
**調性**：穩健告知，不急不躁
**讀者心理**：「噢對，這個東西我有印象，還沒買。」

#### 內容公式
```
① 倒數標記（最後倒數 7 天 / 募資倒數 7 天）
② 里程碑宣告（募資突破 XXX 萬 / XXX 人贊助）
③ 核心賣點完整陳列（3-5 個，用結構化格式）
④ 價格錨點（最低只要 $XXX / XX 折最後機會）
⑤ CTA 連結
```

#### 重點
- 賣點要「完整」，這是最後一次完整展示產品的機會
- 里程碑數字建立社會認同（「這麼多人買了，應該不錯」）
- 語氣平穩，不需要太多驚嘆號

#### 範例句型
- 「募資突破 XXX 萬，感謝大家的支持！」
- 「最後 7 天，把握最優惠價格入手 [產品名]」
- 「優惠最後倒數 ➜ [連結]」

---

### 節點二：倒數 5 天——「不只我說好，大家都說好」

**核心任務**：用第三方證言補強信任
**調性**：信任補強，社會認同
**讀者心理**：「看起來不錯，但真的好用嗎？」

#### 內容公式
```
① 倒數標記 + 里程碑更新
② 「好評推薦」主題宣告
③ 2-3 組 KOL / 使用者推薦（名稱 + 引言摘錄 + 連結）
④ 核心賣點精簡版（3 點速覽）
⑤ CTA 連結
```

#### 重點
- KOL 引言要有「畫面感」——不是說產品好，而是描述使用場景
- 推薦人要有差異性（不同身份、不同使用情境）
- 賣點只保留精華，不再完整展開

#### 範例句型
- 「好評推薦一次整理給你」
- 「還在猶豫嗎？來看看真實體驗」
- ＠KOL名稱 ＃一句話標籤
- 「 引言內容用引號框起，控制在 2 行內 」

---

### 節點三：倒數 3 天——「重點幫你整理好了，快做決定」

**核心任務**：濃縮資訊，加速決策
**調性**：加速決策，開始施壓
**讀者心理**：「好像該買了，但我需要一個理由。」

#### 內容公式
```
① 「最後 3 天」強調語氣升級
② 「必買重點快速整理」格式（編號列點）
③ 可聚焦單一產品線或特定使用場景
④ 「不再延長」「絕不延長」首次出現
⑤ CTA 連結
```

#### 重點
- 資訊要「濃縮」——之前講過的賣點現在變成一行一個
- 可以換個角度切入（例如從場景切入、從痛點切入）
- 「不再延長」是這個節點的新武器，首次亮出
- KOL 推薦可以繼續露出但退為輔助

#### 範例句型
- 「必買重點快速整理 ⬇️」
- 「▌1 [賣點一]  ▌2 [賣點二]  ▌3 [賣點三]」
- 「優惠倒數 3 天 ⏰ 不再延長」
- 「錯過愕惋｜必買重點整理」

---

### 節點四：倒數 1 天——「最後一天，錯過就沒了」

**核心任務**：全力催單，情感訴求
**調性**：最後機會，營造遺憾感
**讀者心理**：「天啊真的要結束了，不買會後悔嗎？」

#### 內容公式
```
① 「最後 1 天」「明天 23:59 截止」明確 deadline
② 情感語言加重
③ 完整產品利益點回顧（幾乎再講一輪）
④ 募資專屬福利完整列舉
⑤ 全渠道齊發（貼文 + EDM + LINE + MSG）
⑥ CTA 連結
```

#### 重點
- 這是「回馬槍」——把所有賣點再完整講一遍，因為有人第一次看到
- 情感語言出現：「猶豫就錯過一輩子」「真心推薦」
- 募資專屬福利要完整列出（折扣、贈品、保固、分期、免運...）
- EDM 的語氣從「告知」變成「對話」（像寫信給朋友）

#### 範例句型
- 「最❗️後❗️一❗️天❗️」
- 「募資優惠只到明天 23:59，絕不延長！」
- 「猶豫就錯過一輩子 😭」
- 「還在猶豫的朋友們，立即下單去吧」
- 「現在就是最優惠的時候～再猶豫你就要錯過囉！」
- 「＼ 最・後・１・天 ／」
- 「＼ 絕・不・延・長 ／」
- 「＼ 倒・數・計・時 ／」

---

### 節點五：倒數 6 小時（或 12 小時）——「最後通知」

**核心任務**：臨門一腳，終極催促
**調性**：建立恐懼，錯過就漲價
**讀者心理**：「完蛋，今天是最後一天！」

#### 內容公式
```
① 「最後 6 小時」「最後通知」
② 極致精簡：核心價值一句話
③ 「錯過就漲價」「未來只能原價購買」
④ SMS 首次出場（一句話 + 連結）
⑤ CTA
```

#### 重點
- 不再說服，只做提醒——默認讀者已經知道產品是什麼
- SMS 是全新渠道，控制在 70 字以內（含連結）
- 貼文和 EDM 可以用「如果你也期望 ✅...」的條件句做最後說服
- 語氣從「推薦」轉為「你確定要錯過嗎」

#### 範例句型
- 「🔥 倒數 6 小時 🔥」
- 「⚠️ 最・後・通・知 🕛」
- 「最後 6 小時後正式結束」
- 「錯過未來原價見」
- 「真的沒開玩笑，時間已經所剩無幾啦 🥹」

#### SMS 範例
```
【最後12小時截止】[產品名]｜$X,XXX 一次全部入手，再送 [贈品]>> [連結]
```
```
【最後１天】[產品名]｜[核心賣點一句話]，[折扣]最後機會 現省$X,XXX＞ [連結]
```

## 3. 五個渠道的角色定位與模板

### 3.1 貼文（Facebook）

**角色**：內容母版，承載最完整的產品資訊
**長度**：300-600 字
**特色**：大量特殊符號排版，視覺層次分明

#### 固定結構
```
標題：[倒數標記] + [產品名] + [核心價值一句話]
連結：[UTM 格式的自訂文字，如「最後機會.x.義式現萃帶著走」]

[倒數提醒 + CTA 連結]

[裝飾框] 產品名稱
          核心 slogan
[裝飾框]

[主要內容區]
- 倒數 7 天：完整賣點陳列
- 倒數 5 天：KOL 好評推薦
- 倒數 3 天：必買重點速覽
- 倒數 1 天：完整回顧 + 情感訴求
- 倒數 6H：精簡核心 + 急迫感

[產品名 + 收尾語 + CTA 連結]
```

#### 貼文標題寫法
- 「【 最後倒數 ❼ 天 ⏰ 】[核心價值]｜[產品名]」
- 「【 募資倒數 5 天 🔥 】好評推薦整理｜[產品名]」
- 「【 最後 3 天 ⏰ 】[使用場景]｜[產品名]」
- 「最❗️後❗️一❗️天❗️[核心價值]｜[產品名]」
- 「⚠️最・後・通・知 🕛 募資優惠 6 小時後正式結束 ▶ [產品名]」

---

**角色**：轉化主力，帶折扣碼與完整模組
**特色**：模組化結構，固定 footer

```
發送對象：問卷名單排除購買名單（或問卷＋會員名單）

[主視覺圖]

[情境開場白]
「＼ 最・後・X・天 ／」
或「＼ XX 折優惠限時倒數 ／」

[產品簡介或情感訴求]

[CTA 按鈕] → 募資連結

[KOL 名稱 + 標籤]
「引言」
[CTA 按鈕] → 推薦文連結
```

### 3.3 LINE 推播

**角色**：精簡資訊 + 按鈕導流
**長度**：150-250 字
**特色**：有時分段推播（文字 + 圖片 + 折扣碼）

#### 固定結構
```
[產品名 + 倒數標記]

▌ [主題區塊標題]
✅ / ✦ / ➊ 賣點一
✅ / ✦ / ➋ 賣點二
✅ / ✦ / ➌ 賣點三

▌ 最後 X 天 x 募資限定 ‼️
🔺 / 🎁 福利一
🔺 / 🎁 福利二
🔺 / 🎁 福利三

▌募資限定 XX 折優惠 🎁
▌現省 X,XXX 的優惠組合

快點擊下方按鈕，卡位最後機會▼▼▼

按鈕：[CTA 文字] 👉
連結：[追蹤連結]
```

#### 三段式推播（倒數 1 天 / 6H 適用）
某些專案會在 LINE 一次推三段訊息：
```
第一段文字：折扣碼 + 核心資訊 + 必買重點
第二段圖片：主視覺（圖片插入連結）
第三段文字：折扣碼（單獨一段，方便複製）
```

### 3.5 SMS 簡訊

**角色**：終極收割，僅在最後 12H/6H 使用

**特色**：一句話直擊

#### 模板

## 4. 共用模組

### 4.1 EDM 折扣碼區塊
所有 EDM 都包含此區塊，位置在第一個 CTA 按鈕之後：
```
---
使用折扣碼再折 $XXX 元

您的專屬折扣碼 ↓↓↓
**[折扣碼]**
---
```

### 4.2 EDM 贊助者抽獎區塊
```
---
✨ 贊助者專屬抽獎 ✨

為感謝參與募資的你，我們提供 贊助者專屬 抽獎活動 ❤️
贊助完畢後，請留意「給贊助者的話」，活動詳情會在那邊公布！

📌 立即將這封信件移動至「主要收件匣」，才不會錯過未來的優惠消息、開箱評測、中獎通知等消息！
---
```

### 4.3 EDM 結尾語
```
---
非常謝謝你的支持和關注，希望你會喜歡
《 [產品名] 》
若您有任何問題，歡迎前往[粉絲專頁](連結)私訊小編
```

### 4.4 EDM 發送對象規則
- **問卷名單排除購買名單**（最常見）
- **問卷＋會員名單**（部分專案）
- 概念：已購買的人不需要再收到催買信

## 5. 視覺排版語言

### 貼文裝飾框
用特殊字符建立視覺區塊，常見組合：

```
╭┄┄┄┄   [品牌名]  ┄┄┄┄╮
​                     [slogan 第一行]
          [slogan 第二行]
╰┄┄┄┄    [CTA 語]    ┄┄┄┄╯
```

```
◤ ​ [區塊標題] ​ ◢
```

```
╲⧹ ​ [標題] ​ ⧸╱
```

```
჻჻჻჻჻  [品牌名]  ჻჻჻჻჻
```

```
⋆┄⋆┄⋆  [標題]  ⋆┄⋆┄⋆
```

### Unicode 品牌字體
品牌名稱常使用 Unicode 數學字體（粗體、斜體），例如：
- 𝗣𝗛𝗜𝗟𝗜𝗣𝗦（粗體）
- 𝘿𝙍𝙄𝙋𝙊（粗斜體）
- 𝗢𝘂𝘁𝗜𝗻（粗體混合）
- 𝗥𝗮𝘆𝗡𝗲𝗼（粗體）
- 𝘽𝙇𝘼𝙐𝙋𝙐𝙉𝙆𝙏（粗斜體）

### 數字圈框
倒數天數常用特殊數字：
- ❶ ❷ ❸ ❹ ❺（實心圓）
- ① ② ③ ④ ⑤（圓圈）
- ❼ ❺ ❸ ❶（倒數天數用）
- ➊ ➋ ➌ ➍（粗實心）

### emoji 節奏
每份貼文的 emoji 使用有節制：
- 標題區：1-2 個（🔥 ⏰ 🎊）
- 賣點列表：每個賣點開頭一個（✔ ☑️ ✦ ◉ ☕️ 📱 🔌 🚗）
- CTA 區：1 個（→ ➜ ➤ 👉）
- 不在正文段落中密集使用 emoji

## 6. 調性遞進原則

### 語氣漸強曲線

| 節點 | 語氣強度 | 關鍵詞 | 禁用詞 |
|------|---------|--------|--------|
| 7天 | ★★☆☆☆ | 「最後倒數」「把握機會」 | 「不再延長」「絕不延長」 |
| 5天 | ★★☆☆☆ | 「好評推薦」「真實體驗」 | 「最後通知」 |
| 3天 | ★★★☆☆ | 「不再延長」「必買重點」 | 「最後一天」 |
| 1天 | ★★★★☆ | 「最後一天」「絕不延長」「明天截止」 | 「最後通知」（留給6H） |
| 6H | ★★★★★ | 「最後通知」「就是現在」「錯過原價見」 | （無限制） |

### 內容重複度控制
- 同一專案不同節點之間，核心賣點會重複，但**切入角度不同**
- 7 天＝完整展示、5 天＝第三方說、3 天＝快速整理、1 天＝完整回顧、6H＝一句定生死
- 同一節點的不同渠道之間，內容相似但**精簡程度不同**：貼文 > EDM ≈ MSG > LINE > SMS

### 數字更新
每個節點的「里程碑數字」應該更新（因為募資持續進行中）：
- 7天：「突破 300 萬」
- 5天：「突破 330 萬」
- 1天：「突破 330 萬」
- 如果沒有新的里程碑，可以改用贊助人數
