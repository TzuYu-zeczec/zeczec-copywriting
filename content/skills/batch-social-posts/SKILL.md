# 社群貼文批量產出工具

## 概述

本 skill 用於從產品資訊出發，一次產出多篇不同切角的社群貼文（FB／IG）。流程分為四個步驟，每一步都需要與使用者確認後才進入下一步。

核心原則：先多產不刪減，由使用者修剪後再迭代。

## 依賴的其他 skill

- **crowdfunding-post**：Step 2 主力貼文的 ABCDEF 六段結構與溝通符號通則
- **copywriting-framework**：Step 1 產品分析的思考邏輯底層（桂氏三角、利益階梯、AB 點理論）

執行此 skill 時，同時套用貼文撰寫規範（已自動載入）。

---

## 四步流程

### Step 1｜產品資訊 → 產品重點 + 受眾切角

**輸入**：使用者提供的產品資訊（可以是文字、PDF、xlsx、圖片等任何形式）

**執行內容**：
1. 用桂氏三角做三層定位：
   - 產品定位（帶給消費者什麼好處、夢幻場景）
   - 市場定位（vs 競品的差異、定價位置）
   - 傳播定位（希望消費者怎麼記住它）
2. 拉出利益階梯（產品特色→產品利益→理性利益→感性利益→終極利益）
3. 整理核心痛點（A 點）
4. 推演受眾切角清單（核心 TA + 多組切角方向，每組標明 A 點描述與主打利益層）

**產出格式**：直接在對話中呈現分析結果

**確認點**：向使用者確認產品名稱、分析方向是否需要調整。可先進 Step 2，切角在主力貼文完成後再最終確認。

### Step 2｜完成主力貼文

**依賴**：crowdfunding-post skill 的 ABCDEF 六段結構

**執行內容**：
1. 依照貼文撰寫規範（已自動載入）的 ABCDEF 六段結構
2. 依照 ABCDEF 六段結構，完成一篇完整主力貼文（正式開賣等級，資訊量最大）
3. 這篇是後續所有切角貼文的「母版」——產品名稱框、特色列舉、品牌背書等都從這篇延伸

**可選**：產出痛點型和情境型兩個版本的 C 段，讓使用者選擇方向

**確認點**：使用者確認主力貼文 OK 後，才進入 Step 3

### Step 3｜主動列出切角選項，使用者選定數量

**執行內容**：
1. 根據 Step 1 的產品分析，主動列出四大類切角選項：

   | 類型 | 說明 |
   |---|---|
   | 場景切角 | 特定使用情境（如旅遊、工作、日常、過節等） |
   | 受眾切角 | 特定人群（如新手、媽媽、租屋族等） |
   | 特色聚焦 | 單一核心特色深打（如某技術、某設計亮點） |
   | 促購 / 限時優惠 | 折扣、免運、最後 N 組、節慶掛勾等 |

2. 每類提供 3-5 個具體選項，附上簡短描述
3. 在對話中主動列出各主題類型選項，請使用者回覆要選哪些（各類分開列出）

**確認點**：使用者選定各類各要幾篇、選哪些選項

**參考**：貼文主題分類（已自動載入）中的各主題類型特性與利益階梯涵蓋範圍

### Step 4｜批量產出 → 輸出

**執行內容**：
1. 以文案基礎邏輯（copywriting-framework）為思考底層
2. 以 ABCDEF 格式為框架撰寫所有貼文
   - 主力貼文：嚴格遵循完整 ABCDEF 六段
   - 切角貼文：可參考 ABCDEF，不強制完整，依核心任務調整
3. 先多產不自行刪減
4. 所有貼文整理成一份完整文稿輸出

**輸出格式規範**：
- 不同主題之間用明顯的分隔線（如 ═══════════）隔開
- FB 貼文段落之間的空行使用零寬度空格 `U+200B`（ZWSP），確保從 Google Doc 複製到 FB 時空行不被吃掉
- 每篇貼文上方標示分類名稱和副標題
- 檔名格式：《產品名》社群貼文全集

## 切角貼文的撰寫原則

切角貼文不是主力貼文的「精簡版」，而是換一個 A 點、換一個利益層次重新切入。

- **場景切角**：A 點是「在那個場景下的具體困擾」，主打理性利益 + 感性利益
- **受眾切角**：A 點是「那個人群的特定痛點」，利益階梯依人群調整
- **特色聚焦**：只講一個核心特色打深打透，偏理性利益 + 產品利益
- **促購 / 限時優惠**：價格驅動，快速直白，偏產品利益 + 理性利益

每篇切角貼文的結構可以彈性調整，但至少包含：
- B 段（開場標語 + CTA）
- C 段（痛點或情境）
- D 段（相關特色條列，2-4 個即可，不需全列）
- F 段（結尾 CTA）

---

## 自我檢查清單

完成全部貼文後，逐項檢查：

1. ☐ 每篇貼文的 A 點是否不同（不是每篇都在講同一個痛點）
2. ☐ 主力貼文是否完整涵蓋 ABCDEF 六段
3. ☐ 切角貼文是否有自己的切入角度（不是主力貼文的刪減版）
4. ☐ 每行是否在 20 全形字以內（A 段除外）
5. ☐ 同一篇貼文的段落標題符號是否只用一種
6. ☐ B 段和 F 段是否都有 CTA 連結
7. ☐ 每篇是否用分隔線隔開、空行是否用 ZWSP
