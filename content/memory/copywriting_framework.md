# jerry 的文案撰寫基本邏輯

## 一、策略定位

- 核心TA、次要TA、外擴TA
- 特定情境鋪陳（圍繞使用場景）
- 狙擊主要競爭對手

### 受眾輪廓建立方式（受眾九宮格）
名稱不限於九宮格，核心是從多個維度向下挖掘，重組出預估受眾形象。

**挖掘維度：**
基本資料、心理特質、生活行為、痛點分析、生活風格、工作形象、科技裝置行為

**流程：兩步驟**
1. **敘事重組**：先寫出一段活生生的人物故事（含生活場景、痛點、觸發購買的關鍵）→ 讓文案寫作者真正「看見」那個人，產生情感連結
2. **標籤拆解**：再把敘事拆成廣告投手可直接使用的碎片化標籤（年齡、職業、品牌偏好、行為習慣、平台、KOL類型等）

**例（貓貓鍋，P01 儀式感租屋貓奴）：**
- 敘事：24歲、住台北8坪套房、喜歡Francfranc/MUJI、貓奴、看到開箱限動「朋友問的不是我的貓，是這個鍋」才購買
- 標籤：iOS用戶、Instagram主力、Pinkoi消費族群、嘖嘖支持者、居家佈置/貓咪飼主KOL...

## 二、桂氏三角（三層定位）

### 1. 產品定位（撇除其他因素的產品本身）
- 這項產品替消費者帶來什麼好處？創造什麼價值？
- 規格技術面有什麼突出之處？
- 夢幻場景是什麼？（怎麼用最爽？）
- 「我可以帶給消費者什麼？」→ 從功能出發，往感受延伸

### 2. 市場定位（與競品比較）
- 相對競品，功能、規格、特色處於什麼位置？
- 加入價格考量：定價是定位之王
- 加入「消費者在意什麼」的考量（看比較表）
- 以上「能溝通的才算數」→ 「和別人比起來，這個特色聽起來怎麼樣」

### 3. 傳播定位（消費者認知中，它是？）
- 希望消費者怎樣談論這個產品？
- 希望消費者用什麼形象記住它？
- 消費者要產生什麼感覺，才會對產品有興趣？
- 牽扯文案、影片等所有傳播素材

### ★ 策略「完成」的判斷標準

好的策略具備以下六點：
1. 邏輯順暢清楚
2. 具備可延伸性（可發想社群企劃）、容易找網紅發揮
3. 文字淺顯易懂，讓人想像的畫面清楚
4. 感受明確、打擊點夠痛
5. 市場夠大
6. 要做素材會很有畫面

**最低執行門檻（過了才能動筆）：**
必須同時符合以下三點——
- ✅ 感受明確
- ✅ 文字淺顯易懂
- ✅ 邏輯順暢清楚

六點全中最好，但這三點是底線。

## 三、頁面設計—文字

### 黃金圈理論
- 先問為什麼（Why）→ 怎麼做（How）→ 做什麼（What）
- 由核心消費者問題，往外推到怎麼解決問題
- 例：Apple 設計革命

### AB點理論（XY型文案）
- 文案的本質：移動消費者的狀態

| 場景 | A點 | B點 |
|------|-----|-----|
| 老師 | 學生不懂 | 學生懂了 |
| 銷售 | 消費者不想買 | 消費者想買 |
| 面試 | 面試官無印象 | 留下深刻印象 |
| 告白 | 對方沒太大興趣 | 對方更加喜歡你 |

**產品認知順序（假設）：**
不了解產品 → 已了解產品 → 產生心動
（用戶A點）（文案A點）（B點）

- 兩種視角的差異：用戶A點 ≠ 文案A點
- 透過市場調查確認TA當下的狀態，再透過策略與創意達到想要的狀態
- A點B點之間有無限節點，需要驗證假設

### 段落提煉
- 緊貼策略與切入點
- 先做多再刪減或合併
- **文字與畫面是「一」是「丼飯」**
- 寫文案的人最懂策略，要決定圖片呈現的感覺
- 沒意義的東西才不願意看！頁面停留時間不是重點！

**刪減標準：**
- 沒有固定標準，取決於文體、銷售主策略、段落編排
- 理想是所有內容都貼合主策略
- **AI 協作原則：先多產內容，jerry 會在修改時明確指出哪些可以合併或刪除，不需要自行判斷刪什麼**

### 破題方式
- 暗示策略、整理亮點、建立信心（說明為何研發產品）、提供誘因、感受鋪陳
- **完全可以混用，沒有固定順序**，依策略和產品調整
- 最困難：滿足資訊量 + 快速閱讀

**★ 框架使用的元原則：**
所有知識只是思考的邏輯，都可以融會貫通。沒有哪個段落必須接在哪個段落之後，一切依照策略與產品做調整。框架是思考工具，不是硬性流程。

### 引導思想
- 篩選資料：背景議題理解、是否曾購買類似產品、特定情境描述符合度、選擇考量
- 強化 Why：過去是否碰過痛點、是否知道某問題、對某問題的感受

### 描述（問卷企劃補充）
- 填答過程 = 銷售過程
- 注意手機版填答體驗（60% 以上使用者在手機）

## 四、Dream Brief Checklist（給文案的完美產品說明書）

### 一、產品的核心與靈魂
1. 產品全名 & 一句話介紹
2. 產品的「身世」（為什麼做這個？）
3. 靈感的「啊哈！」瞬間
4. 希望顧客擁有的「感覺」

### 二、戰場與目標
1. 目標客群立體樣貌：輪廓、生活樣貌、價值觀（在乎什麼／嚮往什麼／害怕什麼）
2. 真正的「敵人」是誰？（麻煩？等待？將就？錯誤觀念？）
3. 市場上的「刻板印象」（可以顛覆的點）
4. 產品的「身價」定位（奢侈品？高CP值？聰明投資？）

### 三、武器庫與證據
1. 完整功能規格列表
2. 獨家秘密武器（專利、材料、演算法）
3. 最有料的數據
4. 最強的信任背書（認證、獎項、KOL、用戶好評）

### 四、氛圍與聲音
1. 品牌人設（三個詞）
2. 視覺風格關鍵字

### 五、鬼牌
1. 如果只能說一件事...（電梯30秒版本）
2. 意想不到的隱藏用法
3. 自己最愛的一點（最真實的愛最有感染力）

## 五、消費者購買旅程 & SEO 思路

消費者在購買前會經歷：
1. 比較市場價格
2. 搜尋品牌評價、比較龍頭競品、排名
3. 比較相關型號
4. 搜尋KOL體驗開箱
5. 搜尋使用方式、最佳攻略
6. 搜尋如何維修、保養、解決疑難雜症

→ SEO 內容布局應對應購買旅程各階段的搜尋意圖

## 六、文案建構六步驟（文案建構.md）

1. 目標受眾分析（定位 + 受眾期望 + 人物誌）
2. 找出價值（達成期望的可能性 + 需付出的努力 + 時間差）
3. 選擇適合的媒介（社群/官網/銷售頁/EDM/影片 各有不同目的）
4. 決定文案架構（激化問題+解決方案、前後對比、特點好處證明、故事、AIDA）
5. 視覺元素（寫文案時就要考量畫面；文字與視覺是「一」）
6. 清晰的行動號召（把讀者不行動的理由都考慮進去，逐一排除）

## 七、行銷定位 SOP（行銷定位 SOP.md）

**桂式三角 × 關鍵字架構：**
- 給誰？我是？給什麼？
- 產品定位：受眾、類別、特點
- 市場定位：區隔、用途、理性利益
- 傳播定位：洞察、意義、感性利益

**利益階梯（由淺到深）：**
1. 產品特色（與市場不同之處）
2. 產品利益（買了能有什麼好處）
3. 理性利益（解決什麼問題）
4. 感性利益（給你什麼感覺）
5. 終極利益（喜歡的情感因素）

**利益階梯使用原則：**
- 理想狀態：一段好文案應涵蓋所有層次，方方面面的利益被滿足，受眾心動程度才最高
- 篇幅受限時，依兩個標準取捨：**① 文案長短** + **② 文案主題**

| 媒介／主題 | 涵蓋層次 |
|---|---|
| 銷售頁、主力FB貼文 | 全部層次都必須涵蓋 |
| 分眾切角FB貼文 | 理性利益 + 感性利益 |
| CRM內容 | 理性利益為主 |
| 懶人包、快速認識、促購、痛點解決 | 理性利益 + 產品利益 |
| 品牌理念、使用場景 | 感性利益 + 終極利益 |

- 越短的文案越要直接直白，「有什麼好處」「解決什麼問題」通常是最直接有效的切入
- **產品特色通常被包含在「理性利益」裡面說，不需要獨立出來**（未來大量貼文資料可進一步驗證）

**產品命名原則：**
- 暗示與連結性
- 功能意義
- 視覺意象
- 情感連結

## 八、食物文案結構（食物文案.md）

四段式結構：
1. **動機誘發**：標題（動詞形容）+ 開場白（痛點提問/畫面感）
2. **差異細節**：食材、製作者、製程技術、認證檢驗
3. **場景營造**：最佳吃法、還能怎麼吃、何時、跟誰吃
4. **品牌情感**：故事 + 理念

**命名技巧**：加入動詞的動感（爆肉香腸、火山香腸飯糰）

## 九、舒老師風格觀點（舒老師.md + 舉例實戰.md）

**核心心態：**
- 爽文架構：明確的目的、清晰的框架、作弊的手段
- 用不計後果的心態完成產品的真實感受
- 把產品賣點戲劇化：強調「後果」而非「結果」
- 文案夠辣嗎？夠戳嗎？

**語言技法：**
- 文字帶情緒（不要再OO了嗚嗚嗚）
- 使用「竟然」「甚至」製造驚訝感
- 類比暗示（碳酸=氣泡、火把=冒險、貓肚皮=柔軟）
- 製造衝突/冒犯感（香得令人髮指、讓人咬牙切齒的渴望）
- 自我貶抑比自賣自誇有力（「我們可能比較笨，一條內褲花了40年」）
- 在文案裡找尋人們本來就有的記憶

**正規軍 × 野孩子的共存方式：**
- 兩者完全不衝突，大多數情況下是**同時混用**的，不是先後發生
- 「讓人變得更不理性」是**經過設計的**，目的是達成策略框架設定的目標
- **正規軍**：好好補充產品特色、增加可信度
- **野孩子**：吸睛標題、意想不到的使用場景、圖像創意、增加文字靈活性
- 「戲劇化後果」屬於野孩子技巧之一，**沒有「太誇張」的紅線**，越誇張越吸睛

**類比 vs 暗示（兩個不同技法）：**

類比——從目標物與其他東西「哪邊相似」來發想：
- 相似的使用環境
- 相似的形狀（叉子→「有著跑車般的流線造型」）
- 相似的使用方式（叉子→「像長矛一樣，戳起你的食物，這是戰爭！」）
- 給人相似的感官（叉子鍍銀→「像餐桌上的流星」）

暗示——透過具體物品或感覺烘托氣氛，從使用情境、氛圍聯想那個環境會有什麼：
- 煙硝味 → 暗示戰爭
- 颱風 → 暗示鉅變
- 冰淇淋、夕陽 → 暗示短暫的美麗

- 不做無用的說服，要強化已有的認同感

**舉例對比：**
- 磚頭平庸：「紅砂淬鍊、硬如磐石」→ 優化：「掌骨開放性骨折，他大概就是這麼硬」
- 八寶粥平庸：「食材選得好，渾身都是寶」→ 優化：「下午四點半，餓了怎麼辦？來一罐吧」
- 白菜促銷：「好吃不貴」→「懂得買菜省錢的人，遲早住進大房子」

## 十、氾濫語句禁忌（氾濫的語句.md）

**永遠不要用的空洞詞彙：**
- 顛覆性的創新、改變遊戲規則
- 無與倫比的體驗、全球首創
- 數位轉型新標準、AI驅動的全新解決方案
- 為你量身打造、無縫整合
- 元宇宙/Web3改變一切
- 錯過這次機會就再也沒有了

**避免原則：**
- 務實與透明：用清晰具體的語言說明價值
- 聚焦真實且可驗證的數據
- 不用空泛詞彙堆砌：讓顧客清楚了解產品能解決什麼問題
- 創新要回歸實際效益，不是為了炫技
